# 本地多模型编排与生成模型职责

> 文档状态：当前实施版 v1.0  
> 更新时间：2026-08-24  
> 决策：正式声音分析链路移除 Qwen3.5-Omni

## 1. 决策原因

专业声学模型已经覆盖项目的主要识别任务：

- YAMNet：鸟、蛙、虫、雨水、流水、风和树叶、人声、脚步、交通与机械声；
- BirdNET：杭州鸟类候选与时间区间；
- 非鸟分类头：杭州相关蛙虫候选；
- 音质模块：静音、削波、时长与录音可用性；
- 规则层：阈值、拒识、主次线索、儿童安全内容与结案状态。

在此基础上继续让通用音频多模态大模型听完整录音，会增加延迟、费用、隐私传输和模型冲突，却没有证明能够改变调查决策。因此正式链路不再调用 Qwen3.5-Omni，也不保留运行时fallback。

历史Qwen文档和评测仅作为阶段记录，不再代表当前架构。

## 2. 当前正式链路

```text
录音
→ 48 kHz与16 kHz双路预处理
→ YAMNet通用声景（16 kHz）
  与BirdNET/非鸟分类头（48 kHz）并行
→ 确定性融合与拒识
→ 安全问题策略
→ 儿童现场观察
→ 调查结案或保留不确定
→ 声音邮票
→ 调查完成后生成创作简报
→ Fun-Music音乐 + Qwen-Audio-TTS语音 + Wan画面
→ FFmpeg保留真实原声并合成
```

分析阶段完全本地运行，不依赖通用大模型或网络。

## 3. 各模型职责

| 模型/模块 | 输入 | 输出 | 不负责 |
|---|---|---|---|
| YAMNet | 16 kHz WAV | 通用声景候选、时间片、分数 | 具体物种、儿童叙事、最终确认 |
| BirdNET | 48 kHz WAV | 杭州鸟类候选、embedding、时间片 | 非鸟声景、最终鉴定 |
| 非鸟分类头 | BirdNET embedding | 蛙虫候选、拒识结果 | 开放世界声音、最终鉴定 |
| 规则融合 | 三类模型输出 | 主线索、可能线索、谨慎置信表达 | 创造新候选 |
| 问题策略 | 声音大类、候选和质量 | 审核过的现场问题 | 开放式聊天 |
| 调查状态机 | 问题与人类观察 | 完成/未解决/停止原因 | 物种科研确认 |
| Fun-Music | 创作简报 | AI背景音乐 | 声音识别 |
| Qwen-Audio-TTS | 审核旁白 | 科普语音 | 自由编写事实 |
| Wan | 受控视觉简报 | 自然环境画面 | 生成识别证据 |
| FFmpeg | 原声、音乐、旁白、画面 | 最终明信片 | AI推理 |

## 4. 生成模型如何产生真实价值

生成模型只在调查结束后工作，并消费同一份调查状态。创作简报包含：

-主要声音大类；
-审核过的儿童解释；
-调查状态；
-现场观察的受控摘要；
-仍然存在的不确定性；
-必须保留的真实原声；
-禁止出现的未经确认物种、儿童正脸和危险行为。

观察原文不会直接进入旁白或视频Prompt，避免用户输入污染生成内容。系统只使用受控摘要：

```text
现场观察也记录到了相同声音线索
现场没有再次观察到相同线索，因此仍保留不确定性
现场暂时无法判断，因此保留机器候选
```

生成作品必须表达调查过程，而不是把候选包装成事实。

## 5. 普通多模态模型的未来位置

当前产品没有必须由通用多模态模型完成的核心任务。若未来引入，必须满足“改变行动”标准：模型输出需要实际改变下一步问题、候选范围或恢复建议，而不是只润色文字。

可考虑的未来场景：

1. 用户同时提供照片、短视频和声音，需要跨模态核对生境与可见特征；
2. 学校活动上传观察笔记或手绘记录，需要整理多种证据；
3. 家长需要将多次调查汇总为成长报告；
4. 专家复核需要对声音、图片、地点和观察表进行统一摘要。

这些能力应读取结构化证据，不直接覆盖专业模型和人工审核结果。没有真实多模态输入时，不为了“使用大模型”而增加模型。

## 6. 服务端与云端

### 本地完整版

YAMNet、BirdNET和非鸟分类头并行运行。所有模型在启动时预加载，分析结果进入共享调查契约。

### Vercel轻量版

只部署约4 MB的YAMNet TFLite模型和标签，通过`tflite-runtime`执行通用声景分析。它不提供BirdNET和蛙虫具体物种能力，界面必须明确能力边界。

### Android与ModelScope

继续使用同源YAMNet/BirdNET/非鸟模型资产。三端需要通过模型SHA-256、类别顺序和固定音频夹具维持契约一致。

## 7. 调试与验收

CLI模式：

```text
full      YAMNet + BirdNET + 非鸟分类头
yamnet    只运行通用声景模型
acoustic  只运行BirdNET与非鸟分类头，用于专业模型调试
```

正式验收重点：

-固定录音在Android、本地API、CLI和ModelScope的候选类别一致；
-YAMNet具体类别阈值与移动端一致；
-输入格式错误时明确失败；
-任一模型失败时其他证据仍可展示；
-分析链路不发起通用大模型请求；
-没有完成现场观察时不能开始创作；
-生成视频保留真实原声，并标明AI音乐、语音与画面；
-生成内容不出现未经确认的具体物种事实。

## 8. 迁移边界

- `app/qwen_service.py`与Qwen音频测试脚本已删除；
-正式依赖移除OpenAI SDK；
-CLI移除`qwen`模式；
-评测模式从`qwen`改为`yamnet`；
-Vercel入口改为`vercel-yamnet-only`；
-旧运行包仍可读取，其中历史`models.general_audio`值可能是Qwen，不影响回放；
-历史文档、旧评测数据和旧截图不删除，但必须标注为过期架构。
