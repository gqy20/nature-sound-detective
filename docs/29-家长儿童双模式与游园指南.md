# 家长儿童双模式与亲子游园指南

> 状态：移动端核心闭环已实现并通过模拟器验证；更新时间：2026-08-25

## 1. 产品目标

自然声探员使用同一条调查记录提供两种视角：

- **儿童探索**保护孩子先听、先描述、再判断的自主过程；
- **家长陪伴**提供专业依据、引导方法、安全边界和过程性回应；
- 两种视角共享录音、候选、现场观察、路线进度和声音册，不生成两套数据。
- 录音阶段用 Android PCM 计算的真实 RMS/Peak 驱动环形声纹；分析阶段展示录音文件的真实包络并按模型窗口扫描，回放阶段按播放器实际位置推进。静音与暂停时不制造假波动，帮助儿童理解“声音进入—模型读取—得到线索”的过程。

家长模式不是替孩子确认物种的专家后台。孩子拥有判断权，家长拥有安全与公开边界权，AI只拥有建议权。

## 2. 双模式交互

首页可切换“儿童探索 / 家长陪伴”，选择保存在设备本地。普通游园查看不需要验证；公开、研究贡献、账户管理和批量删除仍应由成年人单独确认。

### 2.1 儿童探索

科普卡优先展示三个核心现场问题：

1. 什么时候发现；
2. 在什么生境活动；
3. 声音有什么规律。

候选始终不是答案，儿童可以选择“暂时不知道”。

### 2.2 家长陪伴

家长结果层包括：

- 候选、模型来源、关键声段和不确定性；
- AI直接生成2—3个可使用的引导方向；
- 每个方向包含“可以说、一起做、需要避免”；
- AI直接生成3—5句基于真实行为的过程性回应。

移动端只发送候选、模型分数、弱声标记、结构化观察和行为ID，不发送录音或儿童身份。AI必须为每句夸奖返回`evidence_behavior`，且该ID必须存在于本次真实行为集合；引用不存在的行为、把候选写成答案、输出空泛夸奖或不安全动作时，整次生成作废并回退审核模板。

家长面板会明确显示“AI根据本次探索直接生成”或“本地审核模板”。AI调用使用匿名Bearer Token并限制频率，网络失败不会阻断调查主流程。

默认免费额度为每个匿名设备20次成功AI生成：

- 使用服务端签名Token中的匿名身份作为额度键；
- Neon原子预留次数，避免并发请求绕过限制；
- 只有`ai_generated=true`才最终扣除；
- 网络失败、模型失败、安全校验失败和模板回退自动退回额度；
- 额度用尽后家长面板显示0/20，并继续提供本地模板；
- 当前没有登录系统，卸载重装可能产生新匿名身份，家庭账户上线后应迁移为家庭额度。

同一次调查使用候选、观察、行为、弱声标记和提示版本生成稳定指纹。服务端先查询 Neon 缓存；缓存命中直接返回原AI内容和当前额度，不重复扣费。缓存未命中时使用数据库唯一键抢占生成权，避免并发打开同一调查造成双重扣费；失败任务会释放占位并退回额度。

声音行为区分：

- `capturedSound`：本次使用麦克风现场录音；
- `importedSound`：导入已有声音文件；
- `recordedSound`：仅用于兼容未区分来源的旧版本。

AI只有在`capturedSound`存在时才能表述“按下录音键、现场录下声音”，只有在`importedSound`存在时才能表述文件导入。夸奖文本、引导目标和家长说法还要通过重复检查。

## 3. 亲子游园指南

家长可以按以下条件筛选试点公园：

- 孩子年龄；
- 可用时间；
- 鸟鸣、蛙虫、流水风雨等兴趣；
- 轻松步行、完整路线或无障碍优先。

推荐综合路线适龄性、路线时长、生境标签、步行偏好和社区数据充分度。每个公园详情展示推荐理由、建议时段、家庭提示、安全边界、三个公开分区和亲子路线。

路线每站同时提供儿童任务、家长引导、进度勾选和“到这里开始聆听”入口。

点击站点聆听后，产品保存公园、分区、路线、站点序号及安全任务确认。录音保存到声音册时保留该上下文，进入公开页面后自动预选对应公园和分区，并将`sampling_mode`设为`guided_task`。只有用户完成路线站点勾选后，才记录`observedSafely`并允许AI据此夸奖。

## 4. 推荐证据边界

社区数据达到`medium`或`high`时，近期有效记录才参与排序并允许展示数值分数。

数据不足时：

- 只显示“很适合 / 比较适合 / 可以尝试”；
- 明确提示“近期数据不足，本次排序未使用动物活动趋势”；
- 不使用“动物最多”“一定能遇见”等表述；
- 不公开精确动物位置。

## 5. 弱声音分层

音质入口区分三种状态：

| 状态 | 产品行为 | 是否进入生态趋势 |
|---|---|---|
| 清晰声音 | 正常分析 | 满足其他条件时可以 |
| 弱但有动态峰值 | 允许模型尝试，提示谨慎判断 | 不可以 |
| 静音或无有效信号 | 建议重新录制 | 不可以 |

弱动态信号使用独立字段保存：

```json
{
  "usable": true,
  "weak_signal": true,
  "ecology_usable": false
}
```

这使儿童可以继续完成教育调查，同时避免放宽门槛污染公园生态趋势。

## 6. 虚拟公园数据

Neon当前包含21条透明演示记录，其中9条覆盖三个试点公园的9个公开分区，每个分区1条。

所有公园虚拟记录：

- 使用固定`demo-2026-*`编号和CC0音频；
- 标题以“公园体验线索”开头；
- 观察首条为“体验数据，不代表杭州实地记录”；
- `model_snapshot.demo=true`；
- `sampling_effort.virtual=true`；
- `audio_quality.usable=false`；
- `ecology_eligible=false`。

虚拟数据可用于地图、分区筛选、音频播放和社区协助体验，永不提高真实数据充分度。

社区接口显式返回`is_demo`；移动端顶部独立显示真实观察数与体验示例数，并提供筛选。公园分区也分别显示真实和体验记录，客户端不再根据标题或昵称猜测数据类型。

```powershell
# 预览
uv run python scripts/seed_community_demo.py

# 幂等写入
uv run python scripts/seed_community_demo.py --apply
```

## 7. 数据与服务结构

```text
Android APK
  ├── 本地：录音、音质检查、YAMNet、BirdNET、现场观察、模式与路线进度
  └── HTTPS API：匿名会话、公园、路线、公开线索和社区协助
         ├── Neon：结构化调查、授权、回应和状态
         └── Vercel Blob：公开短音频与媒体文件
```

APK不包含`DATABASE_URL`、社区签名密钥或对象存储密钥。Release默认访问`https://xykw-api.vercel.app`，也可以通过`COMMUNITY_API_URL`编译参数覆盖。

## 9. 发布与后续验收

移动端arm64 Release包可以本地构建：

```powershell
flutter build apk --release --target-platform android-arm64 --split-per-abi
```

弱声音不计入生态趋势的后端规则需要随`xykw-api`一起部署；在该部署完成前，线上旧后端不会识别新增的`weak_signal / ecology_usable`字段。

AI亲子陪伴接口也需要随`xykw-api`部署。服务端默认使用`PARENT_GUIDANCE_MODE=live`，并按顺序读取`PARENT_GUIDANCE_API_KEY`、`STORY_API_KEY`或`DASHSCOPE_API_KEY`；模型可通过`PARENT_GUIDANCE_MODEL`覆盖，免费次数可通过`PARENT_GUIDANCE_FREE_LIMIT`调整，默认20。

AI缓存需要数据库迁移`004_parent_guidance_cache.sql`。生产响应不返回内部校验详情，具体回退原因只写入服务端结构化日志。

后续仍需完成：

1. 实体Android手机真实麦克风与户外弱声验收；
2. 三个公园至少18条真实观察和3位独立观察者/公园；
3. 一次真实发布、第二设备读取和原设备撤回；
4. GPS、天气、公园开放信息和家庭账户能力。

移动端版本已提升至`0.3.0+3001`。当前Release APK仍使用debug signing key，只适合比赛和内部试用；正式分发前必须配置独立release keystore并保存签名备份。
