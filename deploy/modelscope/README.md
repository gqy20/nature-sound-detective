# 自然声探员

面向城市儿童与家庭的自然声音调查产品。孩子录下鸟鸣、蛙鸣、虫鸣和环境声，本地声学模型提供候选与有效声段，孩子再通过回听和现场观察完成求证。

## 在线展示能力

- 与 Android 端同源的 YAMNet、BirdNET 2.4 和本地非鸟分类头；
- 最长 20 秒自然声音录制或上传；
- 与移动端同源的清晰、弱动态、无效声音分层；
- 候选、线索强弱、有效时间段与现场观察任务；
- 家庭陪伴、共听杭州、亲子游园与自然册的组件化产品导览；
- 产品闭环、技术架构、隐私、许可与模型能力边界说明；
- Android APK、完整 Web 产品与 GitHub 项目入口。

页面顶部可在“声音分析”和“完整体验”之间切换。声音分析在当前创空间的 CPU
环境内完成；完整体验展示 Android 0.4.0 已实现的核心流程，不在创空间内建立真实
家庭会话、写入社区数据或调用需要云端密钥的共创模型。

完成一次真实分析后，可以继续：

- 在儿童视角回答一项现场观察问题，并保留“暂时不清楚”；
- 切换家长视角，查看基于候选类别的本地审核引导模板；
- 将候选、声音质量、分析时长和现场观察下载为本地文本调查卡；
- 调查卡只在浏览器生成，不写入创空间、社区或训练集。

录音区提供一条公共领域流水示例，用于没有麦克风或暂时没有录音的访客。示例来源为
Wikimedia Commons `Flowing-water-100019.ogg`，作者 Fg2，public domain；完整许可记录位于
`assets/ui/examples/flowing-water-public-domain.license.json`。

## Android 0.4.0 完整体验

- 儿童探索与家长陪伴双视角，共享同一条调查记录；
- 通过 6 位连接码建立家庭会话，只同步结构化探索事件；
- 共听杭州动态地图，区分真实观察与透明体验数据；
- 按年龄、可用时间、声音兴趣、步行偏好和无障碍要求推荐亲子路线；
- 私人自然册、现场观察、社区授权与 AI 自然明信片完整闭环。

创空间中的连接码和自然册社区状态是产品导览组件。游园选择器会根据年龄、时间、声音
兴趣和步行偏好在三个试点公园之间实时更新推荐，但使用的是内置产品规则与展示快照。
需要真实家庭连接、
路线进度、社区协助和作品生成时，请下载 Android 版或打开完整 Web 产品。

## 声音质量策略

创空间对解码后的声音按 3 秒窗口检查动态范围：

- 清晰声音：正常分析，可在满足其他条件时作为生态趋势线索；
- 弱动态声音：允许继续分析，但明确提示谨慎判断且不作为生态趋势数据；
- 静音或无有效动态：不加载模型推理，提示重新录制。

模型分数只用于本次候选排序，不代表物种正确概率。具体物种线索必须通过展示阈值，
否则退回声音大类或标为待核对。

> 模型输出是调查候选，不是专业物种确认。未经人工复核的数据不会自动进入正式训练集或测试集。
