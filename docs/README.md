# 自然声探员项目文档

本目录收录“自然声探员”AI 创意比赛项目的方案与技术调研。

- [创意方案](./01-创意方案.md)：用户问题、产品闭环、功能范围、创新点与比赛展示方式。
- [技术与开源生态调研](./02-技术与开源生态调研.md)：识别模型、音频处理、开放声音数据、许可证风险与验证路线。
- [杭州目标物种调研与筛选](./03-杭州目标物种调研与筛选.md)：杭州夏季候选池、BirdNET 覆盖、数据供给、MVP 名单和现场采集建议。
- [混合声景意见吸收与技术路线修订](./04-混合声景意见吸收与技术路线修订.md)：区分多标签分类、事件检测与声源分离，给出合成混音数据和分阶段实验方案。
- [技术实施方案与项目推进计划](./05-技术实施方案与项目推进计划.md)：统一代码结构、数据流水线、实验顺序、接口、排期、分工、验收指标和风险止损点。
- [BirdNET 基线测试记录](./06-BirdNET基线测试记录.md)：记录 uv/Python 3.11 环境、首轮 E0 结果、问题和下一轮正式测试要求。
- [第一阶段数据整理与 Freesound 背景采集](./07-data-stage-1.md)：现有音频索引、Freesound 五类背景候选、许可证台账、下载与人工审核流程。
- [第二阶段统一标注与 BirdNET 基线](./08-stage2-unified-review-and-baseline.md)：76 条统一复核队列、音质与解码检查、核心物种召回率、候选片段和数据划分结果。

当前阶段目标：以杭州 6 种常见鸟类、1 种蝉和 unknown/background 为首批范围，先跑通混合声景多标签识别与移动端 Demo，再逐步扩展物种、声源分离、自然声音创作和公众参与能力。
