# 杭州目标物种调研与筛选

> 文档状态：第一轮筛选 v0.1  
> 调研日期：2026-07-28  
> 目标时段：7 月下旬至 8 月中旬  
> 目标范围：杭州市中心点约 40 km 半径，比赛移动端 Demo

## 1. 筛选结论

首版建议采用：

```text
6 个 BirdNET 直接覆盖的杭州常见鸟类
+ 1 个黑蚱蝉自定义类别
+ 1 个 background/unknown 非目标类
```

推荐的 6 个核心鸟类是：

1. 鹊鸲；
2. 白头鹎；
3. 乌鸫；
4. 珠颈斑鸠；
5. 红嘴蓝鹊；
6. 黑水鸡。

扩展候选为小䴙䴘和夜鹭；自定义类别首选黑蚱蝉，第二选择为布氏泛树蛙。

这样设计的原因：

- 六种鸟均有杭州夏季观察记录，并包含城市绿地、林地和湿地三类场景；
- BirdNET V2.4 标签已确认覆盖六种鸟，可以快速建立可运行基线；
- 鸟类公开声音多，能较快建立训练和测试集；
- 黑蚱蝉在杭州夏季容易听见和录制，但 BirdNET V2.4 不覆盖，适合展示“本地自定义物种”能力；
- `background/unknown` 用于人声、车辆、风雨、其他鸟和混合声景，避免系统对所有录音强行猜一个物种。

## 3. 筛选标准

每个候选按五项评分，每项 1–5 分：

1. **杭州当季可遇见性**：7–8 月在杭州目标场景出现的可能性；
2. **手机可录性**：声音响度、持续时间、活动时段和环境噪声影响；
3. **模型就绪度**：BirdNET 是否直接覆盖，或是否需要自定义训练；
4. **公开数据供给**：是否容易获得多来源、许可清晰的声音；
5. **儿童内容价值**：声音是否有辨识度，行为故事是否有趣。

评分用于安排开发顺序，不是生态价值评价。

## 5. BirdNET 覆盖核对

本轮读取 BirdNET V2.4 的 6,522 类标签文件，确认：

| 产品中文名 | iNaturalist/当前常用学名 | BirdNET V2.4 标签 | 覆盖 |
|---|---|---|---|
| 鹊鸲 | Copsychus saularis | Copsychus saularis_Oriental Magpie-Robin | 是 |
| 白头鹎 | Pycnonotus sinensis | Pycnonotus sinensis_Light-vented Bulbul | 是 |
| 乌鸫 | Turdus mandarinus | Turdus mandarinus_Chinese Blackbird | 是 |
| 珠颈斑鸠 | Spilopelia chinensis | Streptopelia chinensis_Spotted Dove | 是，存在旧属名映射 |
| 红嘴蓝鹊 | Urocissa erythroryncha | Urocissa erythroryncha_Red-billed Blue-Magpie | 是 |
| 黑水鸡 | Gallinula chloropus | Gallinula chloropus_Eurasian Moorhen | 是 |
| 小䴙䴘 | Tachybaptus ruficollis | Tachybaptus ruficollis_Little Grebe | 是 |
| 夜鹭 | Nycticorax nycticorax | Nycticorax nycticorax_Black-crowned Night-Heron | 是 |
| 黑蚱蝉 | Cryptotympana atrata | 无对应标签 | 否 |
| 布氏泛树蛙 | Polypedates braueri | 无对应标签 | 否 |

珠颈斑鸠必须在物种表中建立 `Spilopelia chinensis ↔ Streptopelia chinensis` 同物异名映射，否则会出现观察数据和模型结果对不上。

本轮只核对了全局标签覆盖，尚未实际运行 BirdNET 的杭州经纬度/周次范围模型，也没有用真实音频测准确率。标签存在不代表杭州手机录音一定识别良好。

## 6. 推荐 MVP 类别定义

### 6.1 六个直接识别类

```text
Copsychus saularis       鹊鸲
Pycnonotus sinensis      白头鹎
Turdus mandarinus        乌鸫
Streptopelia chinensis   珠颈斑鸠（兼容 Spilopelia chinensis）
Urocissa erythroryncha   红嘴蓝鹊
Gallinula chloropus      黑水鸡
```

### 6.2 一个自定义类

```text
Cryptotympana atrata     黑蚱蝉
```

黑蚱蝉具有三个 Demo 优势：杭州盛夏常见、白天即可采集、声音持续且响亮。风险是多只蝉经常形成连续声景，自定义模型必须同时收集“单只近距离”“多只合唱”“交通声中的蝉”和“其他蝉种”样本。

### 6.3 一个非目标类

```text
background / unknown
```

至少包括：

- 无目标生物的城市环境声；
- 人声、儿童说话、脚步；
- 汽车、空调外机、施工；
- 风、雨、水流；
- 麻雀、斑嘴鸭、白鹭等非核心物种；
- 多物种重叠；
- 很弱或过载失真的录音。

## 7. 杭州现场采集路线建议

### 路线 A：城市绿地/校园，清晨

目标：鹊鸲、白头鹎、乌鸫、珠颈斑鸠、树麻雀。

建议条件：日出后两小时内；避开主干道、广场音响和人群。先做这条路线，因为交通方便、重复采集成本最低。

### 路线 B：西溪湿地或安静水体，清晨与傍晚

目标：黑水鸡、小䴙䴘、夜鹭、斑嘴鸭。

注意不要为了靠近声音离开开放步道、追逐动物或播放叫声诱引。夜鹭更适合傍晚，小䴙䴘与黑水鸡更适合在相对安静的水边等待。

### 路线 C：林缘或植物园，清晨

目标：红嘴蓝鹊、白头鹎、乌鸫，以及更多候选林鸟。

### 路线 D：社区大树和林缘，白天

目标：黑蚱蝉。需要同步记录车辆、风和其他蝉声，建立更真实的自定义训练数据。

### 路线 E：池塘与湿地边缘，雨后夜间

目标：布氏泛树蛙及其他蛙类。该路线涉及夜间安全、蚊虫和水边风险，必须两人同行，作为第二阶段扩展。

## 8. 采集规范

每个物种第一轮目标：

- 至少 5 个不同地点或不同个体；
- 每个地点录制 3–5 段；
- 每段 15–30 秒，保留完整原始文件；
- 同时录制 30 段以上纯背景和困难负样本；
- 不播放动物叫声进行诱引；
- 不靠近巢穴、幼鸟或保护物种；
- 不公开精确巢址；
- 记录日期、时间、粗略位置、天气、设备和录音距离估计。

第一轮不要现场把录音直接标成“确定物种”。建议状态为：

```text
unreviewed → AI suggested → human reviewed → expert confirmed
```

## 9. 数据集构建计划

每个核心鸟类先准备：

- 公开训练候选 50–100 条；
- 公开独立测试 20 条；
- 杭州手机实录 15–25 条；
- 与该物种容易混淆的困难负样本 20 条。

黑蚱蝉先准备：

- 公开许可清晰声音 50 条；
- 杭州手机实录 30 条；
- 其他蝉/蟋蟀声音 30 条；
- 城市机械连续噪声 30 条。

公开音频按原始录音 ID 划分训练和测试，不能把一条长录音切片后分到两边。本地录音最好按地点和日期分组划分，测试模型跨地点能力。

## 10. 下一步实验

### P0：BirdNET 杭州范围列表

实际运行 BirdNET 对杭州坐标 `30.2741, 120.1551`、7–8 月对应周次的范围模型，确认六个核心鸟类没有被空间过滤器错误排除。

### P0：公开样本基线

每种先下载 10 条许可清晰的公开声音，不训练，直接跑 BirdNET，记录 Top-1、Top-3 和失败类型。

### P0：本地录音基线

先采集白头鹎、鹊鸲、乌鸫、珠颈斑鸠与黑蚱蝉。它们不依赖进入湿地景区，能最快暴露手机录音、距离和城市噪声问题。

### P1：黑蚱蝉二分类

使用 BirdNET 或 Perch 嵌入训练 `黑蚱蝉 vs background` 小分类器，再逐步加入其他蝉种，而不是第一版直接训练完整昆虫识别模型。

### P1：湿地扩展

在黑水鸡真实样本充足后，再决定是否加入小䴙䴘和夜鹭。若现场录不到，不要仅因为观察记录多就放进现场 Demo。

## 11. 当前决策

第一版固定范围：

```text
核心：鹊鸲、白头鹎、乌鸫、珠颈斑鸠、红嘴蓝鹊、黑水鸡
自定义展示：黑蚱蝉
未知类：background/unknown
候补：小䴙䴘、夜鹭
第二阶段：布氏泛树蛙
```

这是一份“进入数据验证阶段”的名单，不是最终锁定名单。任何核心物种只要在杭州手机录音测试中连续表现差、很难实际采集或容易造成高误报，都应被候补物种替换。

## 12. BirdNET 本地运行记录

早期隔离环境已安装 `birdnet 0.2.16` 并下载 BirdNET V2.4 地理模型，但 Windows + Python 3.12 在 TensorFlow 后端开始地理推理时异常终止。2026-07-28 已改用 uv 固定 Python 3.11.11、TensorFlow/TensorFlow-Intel 2.15.0，并成功跑通 BirdNET V2.4 声学模型、WAV/MP3 推理和 JSON 导出。2026-08-03 又成功运行杭州坐标 `30.2741, 120.1551` 的全年地理先验，并从 6,522 个输出中生成 200 种移动端候选表；原 6 个核心物种的地理排名均在前 78 位。

后续验证顺序：

1. 在当前 uv/Python 3.11 环境复测杭州经纬度与第 31 周地理模型；
2. 若地理模型仍异常，尝试 BirdNET-Analyzer 官方 Windows 安装包；
3. 再失败才切换 WSL/Linux 或容器；
4. 如范围模型仍不稳定，Demo 暂时使用人工维护的杭州候选列表进行过滤。

范围模型只是降低误报的先验过滤，不应阻塞声学识别基线和数据采集。
