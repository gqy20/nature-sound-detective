# 自然声音创作闭环实施

当前识别起点使用本地 YAMNet、BirdNET 与非鸟分类头；创作阶段统一使用阿里云百炼北京地域的 Fun-Music、Qwen-Audio-TTS 与 Wan，并只在调查完成后消费受控创作简报。

## 当前流程

```text
录音 / 上传
  → 本地声学模型生成声音候选
  → 生成儿童科普卡、旁白稿和观察问题
  → Fun-Music 生成无人声纯音乐
  → Qwen-Audio-TTS 生成中文旁白
  → Wan 2.7 生成 9:16 科普画面
  → FFmpeg 混合音乐、旁白与孩子采集的自然原声
  → 页面播放、下载并保存到声音册
```

识别与创作是两个独立任务。音乐、旁白或视频失败不会破坏声音卡片；已经完成的媒体会写入任务 JSON，刷新页面或重启服务后仍可恢复。

## 模型与降级策略

### 音乐：Fun-Music

默认模型为 `fun-music-v1`，调用百炼北京地域的 `/services/audio/music/generation`：

- 使用 `is_instrumental=true` 生成无人声纯音乐；
- 提示词包含声音大类、儿童探索氛围和配器约束；
- 返回临时 MP3 URL 后立即下载到本地；
- 下载后默认截取 20 秒并淡入淡出，不长期保留整首生成曲；
- 接口失败时使用孩子采集的自然原声叠加本地轻旋律，页面标注为“原声混音”。

### 旁白：Qwen-Audio-TTS

默认使用 `qwen-audio-3.0-tts-plus` 与 `longanlingxin` 音色：

- 旁白由地点、声音类型、简短知识点和观察状态组成；
- 使用温暖、平静、略慢的自然教育讲述方式；
- 输出 MP3，并启用 AIGC 隐性标识；
- 旁白失败时仍继续制作音乐和视频。

### 视频：Wan 2.7

默认使用 `wan2.7-t2v`：

- 720P、9:16 竖屏；
- 时长根据旁白长度限制在 5–15 秒；
- 无字幕、无文字、无儿童正脸；
- 不确定物种时只表现环境线索；
- 标注 AI 水印。

`WAN_VIDEO_MODE` 支持：

- `mock`：默认，本地生成占位画面，不请求付费 API；
- `reuse`：复用指定或最近的本地成片；
- `live`：显式调用 Wan，只用于最终验收。

Live 任务 ID 会立即持久化，重试时继续查询原任务，避免重复提交付费任务。

## 最终混音

最终视频包含三层声音：

1. Fun-Music 背景音乐，基础音量 22%；
2. 孩子采集的自然原声，基础音量 18%；
3. Qwen-Audio-TTS 旁白，作为主声道。

旁白出现时使用 sidechain compression 自动压低背景音乐，结尾统一限幅，输出 AAC 160 kbps。旁白不可用时退化为音乐配画面。

## 数据与隐私边界

- 百炼音频模型只接收音乐提示词和旁白文本，不上传孩子的原始录音；
- 原始录音只在本地用于识别和最终自然声混音；
- Wan 只接收文字画面提示词；
- 本地产物位于 `outputs/mvp/generated/`，默认随运行时数据清理，不进入 Git。

## 配置

`.env` 至少包含：

```dotenv
DASHSCOPE_API_KEY=...
```

推荐配置：

```dotenv
DASHSCOPE_WORKSPACE_ID=
DASHSCOPE_MUSIC_MODEL=fun-music-v1
DASHSCOPE_SPEECH_MODEL=qwen-audio-3.0-tts-plus
DASHSCOPE_SPEECH_VOICE=longanlingxin
DASHSCOPE_MUSIC_EXCERPT_SECONDS=20
WAN_VIDEO_MODEL=wan2.7-t2v
WAN_VIDEO_MODE=mock
WAN_VIDEO_REUSE_PATH=
```

没有 Workspace ID 时兼容百炼公共域名；填写后自动使用北京业务空间专属域名。

## 验证边界

- 自动测试覆盖单 Key 音乐、旁白、视频契约、音乐失败后的本地混音以及任务恢复；
- 当前 Key 的模型列表已包含 Fun-Music、Qwen-Audio-TTS、Wan 2.7 与 Wan 3.0；
- 已使用极短文本实调 Qwen-Audio-TTS 公共域名；
- 完整音乐和视频生成会产生费用，只在明确验收时调用。
