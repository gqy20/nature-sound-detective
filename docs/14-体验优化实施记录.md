# 自然声探员体验优化实施记录

> 注：本文中的Qwen链路为当时真实回归记录。2026-08-24后正式分析已迁移为本地YAMNet/BirdNET/非鸟分类头，历史耗时不代表当前版本。

实施日期：2026-07-31  
依据：[剩余体验优化清单](./13-剩余体验优化清单.md)

## 本轮目标

在不改变现有视觉语言和技术栈的前提下，把 MVP 从“完成一次识别”推进到“比赛可稳定演示、户外可连续采集、结果可反馈、录音可删除”。

## 已完成

### 1. 比赛演示兜底

- 首屏增加“试用示例”。
- 示例不调用远程模型，不需要麦克风权限和测试录音。
- 示例明确显示“示例结果”，不会写入真实声音册，也不开放模型纠错。

![示例结果](../outputs/implementation-audit/05-demo-final.png)

### 2. 首屏信息与隐私

- 首屏增加“声音册”和录音保留提示。
- 页脚增加“录音与隐私”详情。
- 明确录音用于本次识别，服务器默认保留不超过 24 小时。

![优化后首屏](../outputs/implementation-audit/01-home.png)

### 3. 录音质量检查

- 浏览器本地解码录音并计算 RMS、静音比例和削波比例。
- 提交前提示“适合识别”“声音偏小或静音较多”“声音过强”。
- 无法解码时直接禁止提交，避免等待服务器返回格式错误。
- 文件名降为次级信息，主标题显示“已有录音”。
- 超过 15MB 的录音在浏览器端直接拦截。

### 4. 手机结果顺序

- `760px` 以下改为先显示儿童解释和观察问题，再显示声音卡片及保存按钮。
- 桌面端保持原有双栏结构。

### 5. 结果纠错

- 真实结果增加“像 / 不太像”。
- “不太像”可选择正确的声音类别或“听不出来”。
- 更正结果通过 `/api/feedback` 保存最小必要字段：任务 ID、是否正确、更正类别、时间。
- 网络失败时先保存在当前设备，避免反馈丢失。

### 6. 本机声音册

- 真实识别完成后自动保存至当前设备，最多 12 条。
- 显示时间、地点、声音类别和卡片标题。
- 支持查看、单条删除和删除全部本机记录。
- 服务重启后会恢复 24 小时内的任务元数据，使声音册仍能读取录音。

![声音册](../outputs/implementation-audit/03-album.png)

### 7. 错误恢复

- 文件过大、格式问题、超时和网络错误使用不同标题与操作按钮。
- 程序聚焦错误标题时不再出现大面积浏览器默认轮廓。
- 15MB 以上录音显示“重新选择录音”，不会进入上传等待。

![文件大小错误](../outputs/implementation-audit/04-file-error.png)

### 8. 录音清理与主动删除

- 服务启动、每次分析前和后台每 15 分钟运行清理。
- 上传录音和任务 JSON 超过 24 小时后删除。
- 新增 `DELETE /api/jobs/{job_id}`，声音册删除会同步请求删除服务器录音。
- 纠错记录不保存音频内容。

## 验证结果

- `uv run pytest -q`：10 项测试通过。
- JavaScript 语法检查通过。
- Python 编译检查通过。
- 浏览器验证通过：示例、音质提示、真实识别、纠错提交、声音册保存、单条删除和文件大小错误。

## 当前限制

- 真实 390px 手机、iOS Safari、安卓 Chrome 和微信内置浏览器仍需设备回归。
- 浏览器震动、录音结束前 3 秒倒计时尚未实现。
- 本机声音册没有账号同步；清除浏览器数据会删除本机记录。
- 服务器录音删除依赖本地 MVP 服务，未来部署到云存储后需改为对象存储生命周期策略。
- 当前示例没有配套示例音频，主要用于稳定展示结果结构。

## 真实回归补充

2026-07-31 的真实端到端回归中，Qwen/BirdNET 链路耗时约 51.1 秒，因此等待提示由“20–40 秒”校准为“20–60 秒”，延迟提醒阈值同步调整为 60 秒。详细结果见[真实回归测试报告](./15-真实回归测试报告.md)。
