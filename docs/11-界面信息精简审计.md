# 自然声探员：界面信息精简审计

更新日期：2026-07-31

## 审计目标

减少儿童主流程中的重复说明、技术措辞和视觉已经表达过的信息，同时保留操作可理解性、识别可信度与无障碍语义。

## 主要发现与处理

| 页面 | 原有问题 | 优化处理 |
|---|---|---|
| 录音首屏 | 介绍和计时器都说明录音时长 | 介绍只说产品价值，时长只保留在录音控件旁 |
| 录音首屏 | 径向波形中央仍显示“听” | 保留状态圆点，删除文字 |
| 录音首屏 | 浏览器会显示权限提示，页面又提前解释一次 | 首屏只保留录音质量建议，权限失败时再给解决方法 |
| 录音首屏 | “或选择已有录音”中的“或”依赖位置关系 | 改为“选择已有录音” |
| 准备页面 | 波形、文件名和“录音准备好了”重复表达状态 | 删除状态标签，只保留波形和文件名 |
| 准备页面 | “开始寻找声音线索”偏长 | 改为“听听这是什么” |
| 分析页面 | “正在聆听”、阶段标题、阶段说明和进度条同时出现 | 只保留阶段标题、真实波形和进度条 |
| 分析页面 | 向儿童展示 Qwen、BirdNET 和模型合并过程 | 移除模型名称，使用自然语言阶段名称 |
| 结果页面 | 页面标题与声音卡标题重复 | 页面标题仅供屏幕阅读器使用，视觉标题只在声音卡出现 |
| 结果页面 | 声音类型在声音卡和故事标签中重复 | 类型保留在声音卡，故事区标签改为无障碍隐藏文本 |
| 声音卡 | 径向图中央再次写“声音指纹” | 删除中央文字，让图形自行表达 |
| 声音卡 | “每一段自然声音，都有自己的形状”解释已经看见的图形 | 删除装饰性说明 |
| 声音卡 | 免责声明过长 | 改为“AI识别，仅供观察参考” |
| 家长区域 | “家长查看识别依据”和“它为什么这样判断”重复 | 保留折叠标题，内部标题转为屏幕阅读器文本 |
| 鸟种候选 | 百分比后再次写“候选分” | 只显示百分比 |
| 全局页脚 | 重复说明模型和专业确认 | 改为“识别结果仅供自然观察参考” |

## 保留文字的判断标准

- “开始录音”不能只用圆点替代，儿童和首次用户需要明确动作名称。
- “地点”不能删除，它是输入框的必要标签。
- “播放录音”和“保存卡片”仍保留文字，避免只使用不够明确的图标。
- 安全提示、观察问题和不确定性说明属于任务内容，不作为冗余删除。
- 声音卡中的品牌、标题、声音类型和简短免责声明是下载后仍需独立成立的信息。

## 优化结果

首屏每块文字现在只承担一种职责：品牌、价值、操作、录音限制、录音质量和结果边界。分析页由四层说明压缩为“阶段标题 + 波形 + 进度”。结果页去掉重复标题和重复类别，儿童首先看到声音卡、操作按钮和科普故事。
