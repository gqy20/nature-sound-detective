# 三公园真实数据激活与决赛验收

> 状态：执行中
> 更新时间：2026-08-25

## 1. 目标

在不伪造生态结论的前提下，让三个试点公园各自达到首个`medium`数据门槛：

```text
每个公园 >= 6条有效真实声音
每个公园 >= 3位独立观察者
每个公园覆盖3个公开分区
建议覆盖 >= 2个观察日
```

三公园合计最低18条真实观察。比赛体验数据和Freesound素材只用于界面体验，永不进入生态聚合。

## 3. 单条记录验收

- 使用真实现场录音，不使用下载素材或AI生成音频；
- 音频质量`usable=true`；
- 选择正确公园与公开分区，不上传精确坐标；
- 至少完成两个现场观察维度；
- 成年人完成独立公开授权；
- `model_snapshot.demo`不得为`true`；
- AI图片或视频可以随帖子展示，但不作为生态证据；
- 不追逐、诱拍或接近动物，不离开公开步道。

## 4. 每轮采样后的检查

```powershell
uv run python scripts/audit_pilot_coverage.py
uv run python scripts/audit_pilot_coverage.py --json
uv run python scripts/audit_pilot_coverage.py --require-medium
```

`--require-medium`在任一公园未达到门槛时返回退出码3，可用于决赛前验收。

## 5. 决赛演示检查

1. 线上健康页三个资源均为`true`；
2. 使用真机录制并完成本地识别；
3. 完成环境、行为和声音节奏观察；
4. 生成动物故事与自然作品；
5. 选择公园分区并发布；
6. 地图出现帖子及作品来源标签；
7. 生态快照只增加真实可用记录；
8. 每日声讯展示数据充分度、事实、可能原因和观察任务；
9. 打开亲子路线并完成至少一站任务；
10. 撤回演示帖子，确认媒体与公开记录不可访问。
