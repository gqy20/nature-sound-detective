# 多类群声学识别接入

## 当前交付边界

- 鸟类：BirdNET 2.4 使用杭州全年地理先验筛选的 200 种候选，服务端和 Flutter 共用 `mobile/assets/labels/birdnet_hz.json`，不是原来的 6 种白名单。
- 蛙类与鸣虫：训练、评测、TFLite 导出和端云推理链路已经接入。当前仓库中的 `nonbird.json` 明确标记为 `available: false`，真实审核数据不足时不安装模型，也不伪造具体物种结果。
- 声景大类：Qwen/YAMNet 继续负责鸟、蛙、虫、流水、风、人声和交通等多标签场景；专业分类器只增强物种候选。

## 运行链路

录音上传后生成两份单声道 PCM：48 kHz 生物声学主文件供 BirdNET 与蛙虫分类头使用，16 kHz 副本供通用声音模型使用。这样不会在上传阶段丢掉蛙虫常见的高频线索。

BirdNET 每 3 秒产生 6,522 个鸟种分数和一个 1,024 维嵌入。鸟类分支仅保留杭州 200 种目录；非鸟分支复用同一嵌入，经过独立多标签 MLP 分类头输出蛙类、鸣虫和背景类别。融合层保留混合声景中的多个类别，并把具体物种统一放入 `detections[].specific_species`。

## 数据和训练

1. 使用采集脚本生成统一候选清单，或复制 `data/metadata/curated_nonbird_sources_template.csv` 接入国内博物馆、专题库与研究团队授权数据。
2. 下载候选音频并在本地复核页面逐条确认。脚本不会把 `pending`、未知许可、禁止演绎或缺少本地音频的记录送入训练。
3. 从已审核候选生成 `data/metadata/nonbird_training_manifest.csv`，其中包含真实音频路径、类群标签、来源、许可证、复核状态和分组 ID。
4. 只允许 `human_reviewed`、`expert_confirmed` 或 `approved` 样本进入正式训练；同一原始录音或同一采集组不能跨训练、验证和测试集，避免切片泄漏。
5. MVP 优先训练黑蚱蝉；布氏泛树蛙以及 `other_insect`、`other_frog`、`background` 用于扩展与拒识。类别定义以 `ml/configs/hangzhou_nonbird_species.json` 为唯一来源。

```powershell
# 中国范围内的 iNaturalist 研究级声音元数据；加 --download 才会下载音频
uv run python scripts/collect_inaturalist_sounds.py

# InsectSet459 默认筛选 Cicadidae，每个物种先取 20 条候选
uv run python scripts/select_insectset459.py

# 国内人工整理来源：只有填写直接媒体地址且许可可用的行会被接受
uv run python scripts/import_curated_bioacoustics.py data/metadata/curated_nonbird_sources_template.csv --download

# 浏览器打开 http://127.0.0.1:8766 完成人工听审
uv run python scripts/review_nonbird_candidates.py data/metadata/inaturalist_nonbird_candidates.csv

# 审计并生成正式训练清单
uv run python scripts/audit_nonbird_candidates.py data/metadata/inaturalist_nonbird_candidates.csv --require-ready
uv run python scripts/build_nonbird_training_manifest.py data/metadata/inaturalist_nonbird_candidates.csv data/metadata/curated_nonbird_candidates.csv

uv run python scripts/extract_nonbird_embeddings.py data/metadata/nonbird_training_manifest.csv
uv run python scripts/train_nonbird_classifier.py artifacts/nonbird/embeddings.npz
uv run python scripts/evaluate_nonbird_classifier.py artifacts/nonbird/embeddings.npz artifacts/nonbird/model
uv run python scripts/export_nonbird_tflite.py artifacts/nonbird/model --install-mobile
uv run python scripts/validate_bioacoustic_models.py
```

最后一条命令同时检查 BirdNET 文件哈希、`[1, 144000]` 输入、`[1, 6522]` 鸟种输出、`[1, 1024]` 嵌入输出、200 种目录，以及已安装非鸟模型的输入输出和类别配置。

截至 2026-08-03，仓库保存的 iNaturalist 中国候选快照包含 60 条许可可用的研究级声音：黑蚱蝉 44 条、布氏泛树蛙 16 条；其中 CC-BY 14 条、CC0 4 条、CC-BY-NC 41 条、CC-BY-NC-SA 1 条。本地工作区已经下载全部 60 条音频并记录 SHA-256；其中发现 1 条同源重复，已隔离为 `duplicate`，实际有 59 份唯一音频。音频本身受 `.gitignore` 保护，不进入仓库。其余记录保持 `pending`，尚未被人工确认，因此当前可训练条数仍为 0。

### 来源标签训练版本

根据当前交付选择，另行生成了 `source_curated` 数据版本，直接信任 iNaturalist 的研究级群体鉴定以及 Freesound 的来源查询标签，但不把它表述为人工听审数据。该版本共放行 283 条记录：黑蚱蝉 43、布氏泛树蛙 16、其他蝉科 94、其他蛙类 100、背景 30；训练/验证/测试分别为 196/38/49，五个类别在三个集合中均有正样本。同一观察记录固定在同一集合，原始文件哈希重复项已隔离。

来源标签适合快速训练可运行基线，但其评测衡量的是对来源标签的拟合能力，不等同于杭州公园现场准确率。后续加入公园实录时，应保留一份人工确认的杭州独立测试集。

## 启用门槛

非鸟模型至少要通过独立测试集的逐类召回、精确率和误报检查，并在目标公园的风、雨、人声、交通、鸟鸣混响背景下复测。产品显示沿用“候选”口径，并允许用户反馈；未达门槛的类别留在大类识别，不显示具体物种。

BirdNET 模型采用 CC-BY-NC-4.0，当前适合非商业比赛与研究演示。任何商业发布前都需要重新确认模型、训练数据和声音素材的许可证。
