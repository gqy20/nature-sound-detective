# 2026 挑战数据基线

## 数据边界

- 官方 21 个物种的 33 个标准声音保存在本地 `data/raw/challenge_2026/standard_sounds/`，目录已被 Git 忽略，不提交声音版权素材。
- 约 38GB 野外录音始终保留在赛事资料目录。仓库只保存相对路径、时段、音频参数、时长和 SHA-256 索引，没有复制野外 WAV。
- `ml/configs/challenge_2026_species.json` 是赛事物种的唯一目录；其中记录“普通夜莺/普通夜鹰”的源文件冲突，以及“泽路蛙/泽陆蛙”别名。

## 1. 建立外部数据索引

```powershell
uv run python scripts/index_challenge_2026.py "E:\tmp\生声不息AI挑战资料\2026_07_31_生声不息AI挑战说明" --sha256
```

当前索引包含 6,322 个音频文件，其中 33 个标准声音、6,289 个野外 WAV；另发现 7 个未完成的 `.crdownload` 文件。机器可读结果位于：

- `data/metadata/challenge_2026_audio_index.csv`
- `data/metadata/challenge_2026_data_issues.json`

## 2. 鸟类 BirdNET 基线

```powershell
uv run python scripts/prepare_challenge_standard_audio.py
uv run python scripts/run_challenge_birdnet_baseline.py
uv run python scripts/run_challenge_wild_birdnet.py "E:\tmp\生声不息AI挑战资料\2026_07_31_生声不息AI挑战说明" --max-files-per-period 24
```

12 种鸟中 11 种可映射到 BirdNET；“普通夜莺”因资料中的声音文件实际命名为“普通夜鹰”而暂停自动映射。官方标准声音在阈值 0.05、0.25 和 0.50 下的目标召回分别为 100%、83.33% 和 83.33%。分层抽取 96 份、共 96 分钟野外录音，得到 343 条鸟类候选。野外结果没有真值，只能用于组织人工听审，不能表述为准确率。

## 3. 蛙虫检索与人工审核

```powershell
uv run python scripts/retrieve_challenge_nonbird_candidates.py "E:\tmp\生声不息AI挑战资料\2026_07_31_生声不息AI挑战说明" --max-files-per-period 24 --top-per-species-period 10
uv run python scripts/review_nonbird_candidates.py data/metadata/challenge_2026_nonbird_review_candidates.csv --config ml/configs/challenge_2026_nonbird_species.json
```

检索使用 14 个官方蛙虫标准声音生成 BirdNET 嵌入原型，并按 9 个目标物种 × 4 个时段各保留 10 条候选，共 360 条。每条记录保留外部原文件路径、起止秒数和相似度，审核播放器直接定位原录音片段，不复制录音。

这些候选全部以 `pending` 开始，必须人工确认后才能作为野外标签。相似度不是识别置信度。

## 4. 十二分类实验头

`ml/configs/challenge_2026_nonbird_species.json` 定义 9 个赛事蛙虫物种，加 `other_insect`、`other_frog` 和 `background`。实验头复用了既有 BirdNET 嵌入缓存，并加入许可可追溯的 iNaturalist 来源标签候选。官方标准声音只用于独立覆盖检查，没有进入训练。

当前独立官方检查包含 14 个声源、116 个窗口：声源级召回 78.57%，宏平均 F1 为 0.6309。纺织娘和黑斑侧褶蛙 F1 为 0，孟闻琴蛙召回也偏低。

## 5. 比赛 Demo 接入决策

2026-08-04 决定在比赛 Demo 范围内采用当前十二分类实验头，并接入服务端与 Flutter。这个决定不改变模型的实验性质：

- 结果使用“可能听到”或“声音候选”，不表述为确定鉴定；
- 具体物种没有通过阈值和时序支持时，退回“昆虫鸣叫”或“蛙类鸣叫”；
- `other_insect`、`other_frog` 和 `background` 仅承担拒识与大类兜底，不作为具体物种展示；
- 固定准备官方标准声音和已验证成功片段用于现场演示，自由录音允许无结果；
- 页面保留“AI 根据声音特征提供自然观察线索，结果仅供探索参考”的说明。

正式产品的上线闸门仍然是：完成 360 条野外候选听审，建立按地点和日期隔离的杭州真值测试集，再重新训练和校准。Demo 接入不等于通过正式准确率验收。

## 6. Demo 接入验证

十二分类模型已经安装到 `mobile/assets/models/nonbird.tflite` 和本地服务端模型目录。移动端与服务端元数据都包含 12 个类别及相同输出顺序，TFLite SHA-256 和 `[1, 1024] → [1, 12]` 张量契约校验通过。

服务端使用官方黑蚱蝉标准声音完成了一次真实端到端推理，输出 `Cryptotympana atrata`，置信度 0.9999。这项检查证明安装、BirdNET 嵌入、十二分类头和类别解释链路可以运行，不用于扩大准确率结论。

回归结果：Python 75 项测试通过，Flutter 44 项测试通过，`flutter analyze` 无问题。arm64 Release APK 构建成功，并确认安装包包含新的 `nonbird.json` 与 `nonbird.tflite`。

## 7. 官方参考匹配与稳定性压力测试

2026-08-08 增加了独立的官方参考声匹配层。它不修改 BirdNET 和十二分类头权重，也不把官方标准声加入训练/验证集；每个独立官方声源只生成一个归一化 embedding 原型。运行时只有同时满足分类器最低概率、参考相似度和参考类别领先幅度时，参考声才能作为辅助证据恢复接近阈值的候选，不能单独宣布物种。

```powershell
uv run python scripts/build_official_reference_gallery.py `
  artifacts/nonbird/challenge_2026_combined_embeddings.npz `
  --output data/metadata/challenge_2026_official_reference_gallery.json `
  --metadata artifacts/nonbird/challenge_2026_model/metadata.json
```

官方基线评测会强制关闭这层匹配，防止拿参考库测试自身造成数据泄漏。关闭后原始宏平均 F1 仍为 0.6309；同一批 116 个窗口连续推理 10 次，最大概率漂移为 0，窗口决策一致率为 100%。这只证明当前 CPU 推理的重复确定性，不代表跨手机稳定性。

压力集使用官方蛙虫声音与独立背景声构造 419 份录音、2,838 个三秒窗口，覆盖 `-5/0/5/10/15 dB` 信噪比、±增益、750 ms 时间偏移、混响、手机频响、16 kHz 重采样和 8-bit 量化。参考匹配开启时，各条件九个具体物种的宏平均 F1 为：

| 条件 | 宏平均 F1 |
|---|---:|
| 时间偏移 750 ms | 0.6590 |
| 8-bit 量化 | 0.6502 |
| SNR 15 dB | 0.6506 |
| 降低 12 dB | 0.6464 |
| 提高 6 dB | 0.6428 |
| 混响 | 0.6439 |
| 手机频响 | 0.5702 |
| 16 kHz 重采样 | 0.5842 |
| SNR 5 dB | 0.6087 |
| SNR 0 dB | 0.5297 |
| SNR -5 dB | 0.3950 |

30 个独立纯背景窗口的具体物种误报率为 0。报告保存在 `data/metadata/challenge_2026_nonbird_stress_report.json`。由于正样本仍由官方标准声变换得到，这份结果衡量的是参考匹配抗扰动能力，不是杭州公园泛化准确率；正式闸门仍然需要人工确认的杭州手机实录。
