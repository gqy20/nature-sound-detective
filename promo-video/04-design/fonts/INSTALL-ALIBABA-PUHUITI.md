# 阿里巴巴普惠体 3.0 安装说明

本工程的功能性字体统一使用阿里巴巴普惠体 3.0。请从 Alibaba Design 或阿里官方指定渠道下载，不使用第三方字体打包站。

需要安装以下字重：

- 45 Light；
- 55 Regular；
- 65 Medium；
- 75 SemiBold；
- 95 ExtraBold。

安装后在剪辑软件中确认字体家族名称均包含 `Alibaba PuHuiTi 3.0`，不得混用 1.0 或 2.0。

字体文件不提交到 Git，不随 Premiere、After Effects 或其他工程压缩包分发。接收方从官方渠道自行安装。制作工程应在 `01-source/licenses/` 保存官方下载包附带的法律声明副本，但法律声明中如包含个人信息或非公开下载信息，不提交到公开仓库。
