当前阶段状态：杭州 200 种鸟类候选已经接入服务端与移动端；蛙类和鸣虫的 5 类来源标签基线也已完成训练、导出、安装、推理与融合。该模型用于候选识别，正式场景精度仍需杭州公园人工听审数据验证。
