# 自然声音创作闭环实施

## 当前流程

```text
录音 / 上传
  → Qwen3.5-Omni 判断自然声音大类
  → BirdNET 补充杭州常见鸟种候选
  → 生成儿童科普卡片、旁白稿和观察问题
  → MiniMax Music 3.0 生成纯音乐
  → MiniMax Speech 2.8 HD 生成中文旁白
  → Wan2.7 生成 9:16 科普画面
  → 服务端混合音乐、旁白与孩子采集的自然原声
  → 页面播放、下载并保存到声音册
```

识别与创作是两个独立任务。识别完成后即可查看科普结果；音乐、旁白或视频失败不会破坏声音卡片。创作状态会写入任务 JSON，刷新页面或重启服务后仍可恢复已生成的媒体。

## 模型与降级策略

### 音乐：MiniMax Music 3.0

默认调用 `POST https://api.minimaxi.com/v1/music_generation`，模型为 `music-3.0`：

- 生成无人声纯音乐；
- 提示词包含识别到的声音大类、儿童探索氛围和配器约束；
- 输出 44.1 kHz、256 kbps MP3，并立即下载到本地，避免临时 URL 失效；
- 通过 `MINIMAX_MUSIC_MODEL` 可以显式覆盖模型，但 MVP 默认固定为 3.0；
- 若接口失败，自动使用孩子采集的自然原声叠加本地轻旋律，页面标注为“原声混音”。

### 旁白：MiniMax Speech 2.8 HD

使用官方 WebSocket `wss://api.minimaxi.com/ws/v1/t2a_v2`：

- 默认模型 `speech-2.8-hd`；
- 默认音色 `female-tianmei`，语速 0.95，情绪 calm；
- 旁白由地点、声音类型、简短知识点和观察问题组成；
- 输出 32 kHz、128 kbps MP3；
- 旁白失败时仍继续制作音乐和视频，不阻断创作流程。

### 视频：Wan2.7

使用 `wan2.7-t2v`：

- 720P、9:16 竖屏；
- 时长根据旁白长度计算并限制在 5–15 秒；
- 无字幕、无文字、无儿童正脸；
- 不确定物种时只表现环境线索，不生成具体动物近景；
- 标注 AI 水印。

Wan2.7 是异步任务。服务端轮询任务状态，成功后立即下载临时视频，再用 FFmpeg 合成最终 MP4。

## 最终混音

最终视频包含三层声音：

1. Music 3.0 背景音乐，基础音量 22%；
2. 孩子采集的自然原声，基础音量 18%；
3. Speech 2.8 HD 旁白，作为主声道。

旁白出现时使用 sidechain compression 自动压低背景音乐，结尾统一限幅，输出 AAC 160 kbps。若旁白不可用，则退化为音乐配画面。

## 数据与隐私边界

- MiniMax 只接收生成后的音乐提示词和旁白文本，不上传孩子的原始录音；
- 原始录音只在本地用于识别和最终自然声混音；
- Wan2.7 只接收文字画面提示词；
- 本地运行产物位于 `outputs/mvp/generated/`，默认随运行时数据在 24 小时后清理，不进入 Git。

## 后端接口

- `POST /api/jobs/{job_id}/creation`：开始或重试创作；
- `GET /api/jobs/{job_id}`：返回识别与创作状态；
- `GET /api/jobs/{job_id}/creation/music`：播放或下载音乐 MP3；
- `GET /api/jobs/{job_id}/creation/narration`：播放或下载旁白 MP3；
- `GET /api/jobs/{job_id}/creation/video`：播放或下载最终 MP4。

创作状态包括 `idle`、`queued`、`generating_music`、`generating_narration`、`generating_video`、`composing_video`、`completed`、`partial` 和 `failed`。

## 配置

`.env` 至少包含：

```dotenv
MINIMAX_API_KEY=...
DASHSCOPE_API_KEY=...
```

可选项：

```dotenv
MINIMAX_MUSIC_MODEL=music-3.0
MINIMAX_SPEECH_MODEL=speech-2.8-hd
MINIMAX_SPEECH_VOICE=female-tianmei
WAN_VIDEO_MODEL=wan2.7-t2v
```
