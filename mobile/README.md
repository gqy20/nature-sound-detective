# 听见万物移动端

这是项目的 Flutter 移动端，当前优先交付 Android 比赛版，同时保留 iOS 工程和跨平台业务层。它不是网页的 WebView 包装：录音、音质检查、BirdNET/YAMNet 推理、结果融合、科普卡和声音册都在设备本地运行。只有用户主动进入“创作”并确认后，应用才会使用本机配置的密钥调用音乐、旁白和视频服务。

## 当前链路

1. Android 原生 `AudioRecord` 录制 48 kHz、单声道、16-bit PCM WAV，单次最长 20 秒。
2. 用户也可点击录音按钮旁的音频文件符号，或长按录音按钮，导入 10 分钟以内的 WAV、MP3、M4A、AAC、FLAC、OGG 等系统可解码音频；导入文件只在应用缓存中转换为单声道 PCM WAV。
3. 本地以 3 秒窗口检测有效声音和削波。整段大部分安静不再阻止识别；只要至少一个窗口含有清晰声音，就允许继续分析。
4. YAMNet 将音频重采样为 16 kHz，识别鸟、蛙、昆虫、流水、风雨等通用声音类别。
5. BirdNET 使用 48 kHz、3 秒窗口，在杭州全年地理先验筛出的 200 种鸟类中给出候选。
6. 融合层去重并输出“线索强度、模型来源、时间片”，不把模型分数包装成准确率。
7. 用户可将录音、质量信息和识别结果保存到本地声音册。
8. 科普卡直接读取本地审核资料；用户明确进入“创作”后，才调用阿里云百炼北京地域的 Fun-Music、Qwen-Audio-TTS 和 Wan 生成音乐、旁白与视频。

## 儿童探索与家长陪伴

首页支持“儿童探索”和“家长陪伴”两种视角，模式保存在设备本地，两种视角共享同一条录音、调查记录和声音册。

录音、共听杭州、亲子游园指南和自然册由同一个主功能 `PageView` 承载，可左右滑动切换。录音页原有的共听杭州、游园指南和自然册按钮与滑动共用同一控制器，并随页面位置改变选中状态；不叠加悬浮导航或文字导航。录音、分析或结果浮层期间锁定主页面滑动；全屏地图和二级详情继续使用独立路由，不与主页面争抢手势。

- 儿童探索保留三个核心现场问题：发现时间、活动生境和声音规律，优先保护孩子的自主描述与判断。
- 家长陪伴提供候选依据与不确定性，并请求服务端 AI 直接生成 2—3 个引导方向和 3—5 句过程性回应。请求只包含候选、结构化观察、弱声标记和真实行为 ID，不上传录音或儿童身份；每句夸奖必须引用已发生行为，否则整次输出作废并回退本地审核模板。
- 默认每个匿名设备拥有 20 次免费 AI 亲子陪伴生成额度，只有通过事实与安全校验的成功生成才扣除；超额、断网或模型失败时继续使用本地审核模板。剩余次数由 Neon 持久化并显示在家长面板。
- 相同候选、观察、行为和提示版本生成稳定证据指纹；同一设备重复打开同一调查时读取 Neon 缓存，不再次调用模型或扣除额度。现场麦克风录音与文件导入分别记录为 `capturedSound` 和 `importedSound`，避免 AI 把导入文件夸成现场录音。
- 从亲子路线开始聆听时，当前公园、分区、路线、站点和安全任务确认会写入录音上下文；保存后进入声音册，发布时自动预选对应分区并使用 `guided_task` 采样模式。
- 共听杭州使用服务端 `is_demo` 字段分开显示真实观察和体验示例，并提供“全部 / 真实观察 / 体验示例”筛选。
- 共听杭州进入页面后先显示地图和区域选择摘要，再展示今日推荐、筛选和声音列表。全屏地图默认直接使用可缩放的后端/离线底图，不展示手势教学或功能开启卡；用户主动进入“地图来源与隐私”并同意后才初始化原生高德 3D 地图 SDK。应用不向地图传入孩子位置或录音精确坐标，也不声明定位权限；加载超过 12 秒会自动回退稳定底图，用户可随时撤回同意。
- 家长模式提供亲子游园指南，可按孩子年龄、可用时间、声音兴趣和步行偏好，对现有试点公园与路线进行透明排序。推荐使用生境、路线和社区声音记录，不把上传数量表述为动物数量。
- 路线中的每一站同时展示儿童任务、家长引导、安全边界和“开始聆听”入口。涉及公开和研究贡献的成年人授权仍与普通模式切换分开处理。

音质入口区分清晰、弱动态和不可用信号：最佳三秒窗口达到常规门槛时直接分析；略低于门槛但同时具有明确动态峰值时仍允许模型尝试，并提示家长结合现场证据谨慎判断；持续静音仍会被拦截。公园社区数据未达到中等充分度时只展示“很适合 / 比较适合 / 可以尝试”等家庭适配等级，不显示精确分数，并明确说明排序未使用动物活动趋势。

比赛 Demo 当前安装赛事十二分类非鸟头：9 个官方蛙虫物种，加其他鸣虫、其他蛙类和背景拒识。结果统一作为声音候选；来源标签和官方标准声检查不能替代杭州公园实录验收。

科普卡内置赛事目录中 20 个学名明确物种的轻量 WebP 实拍图，每张都带作者、来源链接和开放许可信息；“普通夜莺/普通夜鹰”冲突条目在主办方确认前不配图，避免展示错误物种。

录音期间会读取 Android 原生 PCM 输入计算出的 RMS 与 Peak：检测到有效振幅后显示“已经听到声音”，按钮外侧的有机声纹环保存最近 3.6 秒能量历史，并以 100ms 采样、120ms 插值平滑跟随声音变化。录音结束后，移动端从 WAV 提取 64 段真实包络；本地识别时扫描线跟随模型窗口进度，原声回放时跟随播放器真实位置。静音、暂停和分析结束后停止运动，不使用与声音无关的循环假动效；系统“减少动态效果”开启时自动关闭连续扫描。质量检查、模型识别和技术错误使用不同文案，避免把“模型暂无候选”误写成“没有声音”。诊断日志保存整段 RMS、峰值、最佳窗口 RMS 和有效窗口数量，不保存导入文件名。

## 本地开发

当前移动端版本为 `0.3.1+3002`。比赛和内部测试 APK 仍使用 Android debug signing key；对外商店或长期分发前必须配置独立 release keystore，不能继续沿用当前签名。

正式版本号只在准备发布时更新。每次修改 `pubspec.yaml` 中的正式版本，必须同时提交代码、创建同名 Git Tag 和 GitHub Release，并上传 APK 与 SHA-256；仅生成 debug APK 或新增 QA 批次不升级正式版本。完整流程见 [`docs/release-process.md`](../docs/release-process.md)。

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

构建 Android arm64 发布包：

```bash
flutter build apk --release --target-platform android-arm64 --split-per-abi
```

科普卡不需要服务端地址或 API Key。创作密钥由用户在 App 设置页填写并仅保存在本机；一个北京地域百炼 Key 即可覆盖音乐、旁白和视频，Workspace ID 可选但推荐配置。自动测试使用替身响应，不会请求第三方生成 API。

地图使用不可互换的平台 Key：后端 `AMAP_GEOCODE_KEY` 提供地理编码和静态图代理；构建机上的 `AMAP_ANDROID_KEY` 绑定 `com.xykw.nature_sound_detective`。debug 与 release 使用同一包名和当前同一签名，因此共用 Android Key；debug 保留日志和调试能力，但不能与 release 并存安装。根目录 `.env` 不进入 Git。

debug APK 默认也连接 `https://listen-api.gqy20.top`，避免真机误连仅模拟器可用的 `10.0.2.2`。需要调试本地后端时显式传入：

```bash
flutter run --dart-define=COMMUNITY_API_URL=http://10.0.2.2:8770
```

应用创建单例分析器，并在首帧后异步预加载 YAMNet、BirdNET 和非鸟分类头。并发的预加载与识别共享同一个加载任务和模型实例；加载失败不会缓存，下一次分析会重试。预加载不阻塞首屏，但首次立即录音时仍可能与后台加载重叠。

本地识别按 BirdNET 的 3 秒窗口逐段发布候选，结果面板会显示当前窗口进度；全部窗口完成后再与并行运行的 YAMNet 结果融合。阶段结果仅作为动态线索，保存、科普卡和创作主题使用最终结果。

最终融合会按语义类别合并不同模型的重复结果并展示共同证据来源。比赛 Demo 优先给出具体鸟种线索：有 YAMNet 鸟类支持时 BirdNET 物种分数达到 0.10 即展示，BirdNET 单独命中时门槛为 0.20；结果页按模型置信度展示最多三个鸟种候选，并明确分数不是准确率。更低的证据标记为“较弱猜想”，不会把它用于创作主题。蛙虫具体物种仍采用更严格的独立模型支持、领先幅度和单模型高分门槛，证据不足时降级为“蛙类鸣叫”或“昆虫鸣叫”；重叠时间窗中证据更弱的冲突类别会降权。赛事鸟种按学名映射到官方中文名，避免 BirdNET 地区标签中的繁体或别名混入界面。

release APK 只打包 CPU 推理库，界面使用平台中文字体，杭州背景图采用 WebP；BirdNET、YAMNet、非鸟分类头和对应标签不会因包体优化而裁剪。

2026-08-04 的 Android arm64 干净 release 构建从 68,050,394 字节降至 51,605,504 字节，减少约 24.2%。包内检查确认三套模型仍在，且不再包含 GPU JNI、AlibabaPuHuiTi 字体和旧 PNG。

## 日志与诊断

首页右上角的诊断按钮可以查看结构化运行事件并导出脱敏 JSONL。一次录音以录音 ID 贯穿端侧分析，一次 AI 创作以作品 ID 串联音乐、旁白、视频、下载和合成阶段。后台 Wan 轮询任务会写入独立的滚动原生日志，并自动合并进诊断导出。Android 实时日志可通过 `adb logcat -s NatureAudio NatureDiagnostic flutter` 查看。完整字段、轮转策略和隐私边界见 [`docs/logs.md`](../docs/logs.md)。

相同 `component + event + error首行` 的错误在 5 秒窗口内只保留第一份完整堆栈，窗口结束后写入一条 `*_repeated` 聚合事件和累计次数，避免框架重建错误在数秒内灌满诊断包。共听杭州额外记录数据加载耗时、结果数量、原生地图可用性、隐私同意和地图 ready/failed 状态。

## 模型与许可

- `assets/models/yamnet.tflite`：YAMNet，Apache-2.0，用于通用声音类别。
- `assets/models/birdnet.tflite`：BirdNET V2.4 FP16，原始输出 6,522 类；`assets/labels/birdnet_hz.json` 保存杭州 200 种候选及输出索引。模型权重为 CC BY-NC 4.0。

BirdNET 可以用于本次非商业比赛原型；如果产品商业化，需要重新确认模型权重授权或替换为许可兼容的模型。模型哈希和标签范围记录在 `assets/models/manifest.json`。

## 当前验收边界

静态分析、单元测试和 Android APK 构建均可在 Windows 完成。仍需在目标 Android 真机上完成麦克风权限、真实录音推理延迟、连续三次全流程、内存和功耗验收。iOS 目录已保留，但签名和真机测试必须在 macOS/Xcode 环境进行。
