# 杭州自然声识别评测实施

## 本阶段目标

把“系统能生成结果”推进到“知道每一类结果是否可靠”。评测分为三条独立链路：

- `birdnet`：只评估杭州 MVP 六种鸟类的候选召回。
- `qwen`：只评估鸟、蛙、虫、风、雨、水、脚步和交通等声音大类。
- `full`：评估比赛现场实际使用的 Qwen + BirdNET 融合结果。

评测不会把文件名或 Freesound 搜索分类当成正式真值。弱标签可用于尽早发现问题，但只有人工听音确认且 `label_status=verified` 的样本才可用于正式准确率。

## 已实现内容

### 评测清单生成

运行：

```powershell
uv run python scripts/build_evaluation_manifest.py
```

输出 `data/metadata/mvp_evaluation_manifest.csv`，当前共 66 条：

- 7 条当前 BirdNET 六种范围内的鸟类样本；
- 交通、脚步、雨水/流水、风和树叶各 10 条；
- 19 条超出当前六种鸟类范围的录音默认不进入本轮物种评测；
- 当前人工确认标签为 0 条。

重新生成清单时，会保留已有的人工标签、是否纳入、复核人和备注。

### 可恢复的批量评测

BirdNET 探索性评测：

```powershell
uv run python scripts/run_mvp_evaluation.py --mode birdnet --include-weak
```

Qwen 声音大类抽样：

```powershell
uv run python scripts/run_mvp_evaluation.py --mode qwen --include-weak `
  --case-id freesound_260726 `
  --case-id freesound_376809 `
  --case-id freesound_173447 `
  --case-id freesound_243880
```

正式评测时不加 `--include-weak`；修改提示词或模型后可加 `--refresh` 忽略缓存。结果写入 `artifacts/evaluation/<时间>/`，同时生成 `latest-<mode>.json`。

## 首轮探索性结果

### BirdNET

- 样本：7 条核心鸟类弱标签录音。
- 成功运行：7/7。
- 0.25 展示阈值下候选命中：4/7，探索性召回 57.1%。
- 珠颈斑鸠：3/3 命中。
- 白头鹎：1/1 命中。
- 乌鸫：0/3 命中。

这不等于正式模型准确率。当前产品只截取录音前 20 秒，乌鸫有效叫声可能不在该区间；还需要人工检查音频区间和低于 0.25 的原始分数。

### Qwen 声音大类

- 抽取交通、脚步、雨水/流水、风和树叶各 1 条。
- 成功运行：4/4。
- 与 Freesound 弱分类一致：1/4，探索性一致率 25%。
- 脚步命中；其余分别被判为鸟类鸣叫、鸟类鸣叫和昆虫鸣叫。

这里的“不一致”也不能直接认定为模型误判：例如交通素材本身包含明显鸟声和脚步，Freesound 分类表示搜索用途，不一定表示录音中的主导声音。四条样本都必须人工听音后再决定是修标签、修改主声音定义，还是调整模型提示词。

## 下一步执行门槛

1. 人工确认至少 30 条声音大类样本：鸟、蛙、虫、风、雨/水、交通各不少于 5 条。
2. 六种核心鸟类每种至少确认 10 条有效片段；当前鹊鸲、红嘴蓝鹊和黑水鸡仍无可评测样本。
3. 人工标注需要写清“主声音”和“同时存在的声音”，避免把多标签问题错误压成单标签。
4. 达到上述规模后，分别报告声音大类宏平均召回率、各类混淆和 BirdNET 候选召回率。
5. 只有识别输出通过门槛后，再把结果送入音乐与视频生成链路。
