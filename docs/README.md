# 自然声探员项目文档

本目录收录“自然声探员”的产品定义、参赛方案、技术调研、实施记录与评测结果。

文档阅读顺序：

1. 先阅读 [产品总纲](./00-产品总纲.md)，理解当前产品定位、核心旅程、范围和平台边界；
2. 决赛评委正文以 [决赛参赛项目说明书 v003](./参赛项目说明书-自然声探员-v003.md) 为当前精简稿，完整证据查阅 [v002 证据底稿](./参赛项目说明书-自然声探员-v002.md)；
3. 再按需要查阅技术、评测、体验、部署和演示专题文档。

- [赛题响应与参赛方案](./21-赛题响应与参赛方案.md)：赛题理解、响应矩阵、核心创新、三分钟演示、数据与评测路线、答辩口径和比赛前优先级。
