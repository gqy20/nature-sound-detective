# 比赛演示与验收清单

## 演示主线

建议把现场演示控制在 3 分钟内：

1. 孩子在杭州公园听见一个看不见的生命，录下一段自然声音；
2. 系统检查录音质量、定位关键片段，给出声音大类、物种候选、判断依据和不确定性；
3. 系统生成一个儿童能在现场完成的观察任务，孩子通过回听和观察补充 AI 无法获得的证据；
4. 完成调查并获得一枚带日期、模糊地点、原声和调查状态的声音邮票；
5. 家长选择仅私人保存、发布匿名探索卡或贡献人工复核；
6. 展示这条待复核记录进入杭州声音地图或复核队列；
7. 用预先生成、保留真实原声的音乐明信片作为结束彩蛋。

核心表达不是“AI 猜中一个名称”，而是“AI 帮助孩子完成一次可理解、可验证、可积累，并能在安全授权下产生公共价值的自然调查”。

音乐、旁白和视频不占据主流程。它们用于证明调查完成后的情感共创能力，不能替代声音证据、现场观察和公众贡献闭环。

## 固定演示资产

正式展示前准备三组已人工确认的杭州录音：

| 场景 | 用途 | 最低要求 |
|---|---|---|
| 清晰常见鸟鸣 | 完整演示调查主线和 BirdNET 候选 | 目标鸟叫位于前 20 秒，关键片段清楚，候选与观察任务已人工审核 |
| 风和树叶或流水 | 展示非物种自然声音和类别边界 | YAMNet 大类候选稳定，儿童解释和安全提示已审核 |
| 混合且较嘈杂的公园声景 | 展示质量检查、不确定性和恢复路径 | 系统应谨慎输出多个线索或建议重录，而非强行确认物种 |

每组都保留原始录音、人工听审记录、预期关键片段、候选结果、观察任务、调查状态和失败分支。完整演示案例还应保留声音邮票、贡献成功状态、地图或复核队列结果、旁白 MP3、20 秒音乐片段和最终 MP4。

比赛现场使用 `WAN_VIDEO_MODE=reuse`，不等待视频服务，也不产生新的费用。地图或复核贡献使用固定、可恢复的演示状态，不依赖现场临时审核。

首批候选已记录在 `data/metadata/competition_demo_candidates.csv`。当前三条均为 `human_verified=no`、`rehearsal_status=pending`，完成听音和至少三次完整彩排前不能称为正式演示样本。

## 故障预案

- 网络正常：现场运行识别，生成内容使用已有视频画面；
- 模型超时：立即切换“试用示例”并解释异步任务设计；
- 网络断开：播放本地固定案例和最终成片；
- MiniMax 失败：使用本地自然原声混音，界面明确标注来源；
- 视频失败：音乐和旁白仍可单独播放，声音卡片不受影响；
- 浏览器刷新：从声音册重新打开服务端任务结果。
- 贡献接口失败：保留本地调查和授权选择，展示“等待同步”，不重复提交；
- 地图不可用：切换到固定复核队列截图或本地演示数据，明确标注为演示状态。

## 隐私与安全说法

- 调查默认私人保存，保存不等于公开或同意研究使用；
- 发布匿名探索卡与贡献人工复核分别取得成年人授权；
- 原始录音只上传到当前服务用于识别，并在默认 24 小时后清理；需要延长保留时单独说明用途；
- MiniMax 只接收音乐提示词与旁白文本，不接收孩子的原始录音；
- Wan2.7 只接收画面提示词；
- 不要求儿童姓名、照片或精确定位；
- 公共地图只展示模糊位置，敏感物种位置进一步模糊、延迟或不公开；
- 录音中的环境人声需要提示、裁剪或风险检查；
- 内容提示词禁止追逐、捕捉、触摸动物，并避免生成儿童正脸。

## 正式验收门槛

- `uv run pytest -q` 全部通过；
- `uv run python scripts/audit_evaluation_readiness.py` 达到人工样本门槛；
- 6 种核心鸟类分别报告候选召回率，不把弱标签当准确率；
- 声音大类报告各类样本数、命中率和主要混淆；
- 390 px 移动端完成录音、质量检查、查看候选、完成观察任务、生成声音邮票和声音册回访；
- 私人保存、匿名发布、贡献复核三种选择的文案和状态正确；
- 贡献失败不会丢失本地调查，不会产生重复提交；
- 地图或复核队列能展示一条来源、权限和审核状态明确的演示记录；
- `mock`、`reuse`、`live` 三种视频模式来源标注正确；
- 仅在最终验收执行一次 Live 视频生成，并记录任务 ID、耗时和费用。

## 答辩时主动承认的边界

- 系统已接入杭州 200 种鸟类候选目录，但正式比赛评测仍以人工确认的核心物种和场景为主；
- 蛙类和昆虫目前以大类识别为主，不承诺具体物种；
- 混合声景存在遮蔽，系统展示候选和不确定性，不替代专家调查；
- 公众贡献是待复核的观察线索，不能自动成为训练数据、正式测试集或科研结论；
- 当前是面向儿童自然教育和公众参与的调查工具，不是生态监测仪器或专业物种鉴定系统。
