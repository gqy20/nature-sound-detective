# 自然声探员品牌标志

## 核心概念

标志是一枚开放的“声音线索印章”：圆环代表一次自然调查与声音邮票，连续声纹代表正在被捕捉的自然声音，右侧缺口表示线索仍可继续验证。

## 标准资产

- `logo-mark.svg`：透明背景图形标志，优先用于网页、印刷与可缩放场景。
- `logo-horizontal.svg`：图形与中文品牌名的横版组合。
- `app-icon.svg`：象牙白底的主应用图标源文件。
- `app-icon-1024.png`：应用商店与不支持 SVG 的场景。
- `favicon-32.png`：浏览器小图标回退版本。
- `apple-touch-icon.png`：iOS 网页主屏图标。

## 色彩

- 森林绿：`#174936`
- 温暖象牙白：`#F8F5EC`
- 品牌文字：`#17251F`

## 使用规则

- 图形标志最小显示尺寸为 `24 × 24 px`。
- 标志四周至少保留内部声纹高度四分之一的净空。
- 小尺寸优先使用图形标志，不要使用横版组合。
- 不旋转、拉伸、添加阴影、渐变或描边，不改变声纹与圆环的相对位置。
- 摄影或复杂背景上应先放置象牙白色底板，确保森林绿标志有稳定对比度。

移动端启动图标由 `app-icon.svg` 生成；Android 另提供自适应前景矢量，iOS 图标保持无透明通道。
