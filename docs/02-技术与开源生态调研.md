# 自然声探员：技术与开源生态调研

> 文档状态：第二轮调研 v0.2  
> 调研日期：2026-07-28  
> 结论适用范围：比赛 Demo 与后续原型验证；许可证信息在正式发布前仍需逐项复核。

## 1. 结论摘要

目前不存在一个同时满足“覆盖中国常见鸟、虫、蛙、兽”“开箱即用”“移动端轻量”“完全无许可风险”的单一项目。最稳妥的 Demo 路线是：

```text
手机网页录音
→ FFmpeg 统一格式并切成 3 秒滑窗
→ BirdNET 验证杭州 6 种核心鸟类基线
→ 单物种干净样本合成 1–3 物种混合声景
→ BirdNET embedding + 杭州 7 类多标签分类头
→ 跨窗口平滑、逐类阈值与 unknown/background 拒识
→ 人工审核的物种知识库
→ 大模型生成儿童化表达
→ 原声 + AI 背景音乐生成声音明信片
```

第一优先级是从混合录音中判断“有哪些目标物种”，而不是把每种声音完整分离出来。声源分离需要更严格的干净声源、混合配对和重建损失设计，适合作为增强实验；不能把面向语音的 TF-GridNet 当成开箱即用的动物声分离器。

数据方面，Xeno-canto 是最实用的全球声音入口，国内还有 BioONE、国家标本资源平台和海南热带雨林鸟鸣数据集等候选来源。但必须保留“单条素材许可证”，不能把“网页能访问”理解成“可任意训练、再发布或商业使用”。

## 2. 开源识别与生物声学项目

### 2.1 BirdNET / BirdNET-Analyzer

- 项目：[birdnet-team/birdnet](https://github.com/birdnet-team/birdnet)
- 完整工具：[BirdNET-Analyzer](https://birdnet.cornell.edu/analyzer/)
- 作用：鸟类及部分其他发声物种识别、声音嵌入、地点/时间过滤、自定义分类器。
- 许可：源码为 MIT；BirdNET-Analyzer 官方说明模型权重为 CC BY-NC-SA 4.0。比赛教育/研究 Demo 可以使用，但未来商业化必须取得额外授权或替换模型。
- 适合度：**最高，建议第一优先验证。**

当前 Python 库可输出 6,522 个物种的分类分数和嵌入，支持根据经纬度与时间缩小候选范围，也支持 CPU/GPU 和离线运行。BirdNET-Analyzer 还提供自定义分类器、评估和片段审核工具。源码许可与模型权重许可不同，参见 [BirdNET-Analyzer 官方仓库的 License 说明](https://github.com/birdnet-team/BirdNET-Analyzer)。

自定义训练文档建议加入 `noise`、`other`、`background` 或 `silence` 非事件类，并以 3 秒片段训练；这与本项目必须处理“不是目标物种”的需求高度一致。[自定义分类器文档](https://birdnet-team.github.io/BirdNET-Analyzer/best-practices/training.html)

需要实测：

- 目标城市常见物种是否在标签集中；
- 中文名称映射是否完整；
- 城市公园手机录音的 Top-1/Top-3 表现；
- 白头鹎、乌鸫、麻雀等相近或背景共现声音的混淆；
- 对蝉、蟋蟀和蛙类的覆盖；
- 位置/周次过滤在中国地区是否有效；
- 模型权重是否允许计划中的公开 Demo 和未来商业化。

### 2.2 Google Perch 2.0 / Perch-Hoplite

- 项目：[google-research/perch](https://github.com/google-research/perch)
- 作用：通用生物声学嵌入、少样本迁移、相似声音检索和多类群识别。
- 代码许可：Apache-2.0；模型本身需查看具体分发页面条款。
- 适合度：**第二优先，适合补充非鸟类和本地小分类器。**

Perch 2.0 从鸟类扩展到更广泛的多类群声音，并适合通过嵌入快速训练小型分类器。[Perch 2.0 介绍](https://research.google/pubs/perch-20-the-bittern-lesson-for-bioacoustics/)

风险是旧 Perch 仓库明确提示部分 TensorFlow 依赖已过时，并建议实际推理研究 Perch-Hoplite。第一阶段不应只押注 Perch，应在 BirdNET 基线跑通后再测试。

### 2.3 OpenSoundscape

- 项目：[OpenSoundscape 文档](https://opensoundscape.org/en/v0.10.1/)
- 作用：音频切片、标签管理、检测/分类模型训练、预测与评估。
- 许可：MIT。
- 适合度：**适合作为数据工程和自定义训练框架。**

它不是一个直接覆盖所有物种的万能预训练分类器，但非常适合把公开录音和本地录音整理为可训练、可评估的数据集。当团队需要自己训练 5–10 类模型时，可与直接写 PyTorch 管线进行成本对比。

### 2.4 AVES

- 项目：[earthspecies/aves](https://github.com/earthspecies/aves)
- 作用：基于自监督学习的动物发声通用编码器。
- 适合度：**研究备选。**

AVES 可将声音转为通用表示，再训练轻量分类头。其价值与 Perch 嵌入路线相似，但集成成本和当前生态需要实测，不进入首周关键路径。

### 2.5 Deep Audio Segmenter（DAS）

- 项目：[janclemenslab/das](https://github.com/janclemenslab/das)
- 作用：动物声音事件的分割、标注和自定义训练。
- 适合度：**当长录音中有效叫声很短时再引入。**

DAS 面向昆虫、鸟类和哺乳类等跨物种声音分割。Demo 初期可以先用能量阈值和滑窗定位有效片段；如果误切严重，再研究 DAS，避免过早增加模型链路。

### 2.6 scikit-maad

- 项目：[scikit-maad](https://scikit-maad.github.io/)
- 作用：时域/频域特征、声景分析和生态声学指数。
- 适合度：**适合频谱分析和未来声景健康度功能，不是首选物种分类器。**

其声学指数更适合后续“公园声景变化”“环境噪声与生物声音占比”等研究。不能直接把某个声学指数解释为生物多样性或生境健康度，必须有生态学验证。

### 2.7 混合声景、多标签与声源分离项目

- [Bird-MixIT](https://github.com/google-research/sound-separation/tree/master/models/bird_mixit)：使用无监督混合不变训练处理鸟类声景，研究方向与本项目最接近，但仍需按其数据和训练条件复现。
- [BioCPPNet](https://github.com/earthspecies/BioCPPNet)：面向生物声学混合信号的目标声音提取研究实现，适合在已有目标类别条件下做增强实验。
- [AudioSep](https://github.com/Audio-AGI/AudioSep)：文本查询驱动的开放域音频分离，可测试“bird chirping”“cicada”等提示词，但泛化到杭州具体物种需要实测。
- [ESPnet / TF-GridNet](https://github.com/espnet/espnet)：TF-GridNet 是强语音分离架构，不是杭州动物声数据上的预训练成品。只有在已构造足够多单源和混合训练对后，才值得进入 P2 实验。

初赛主线采用“合成混音 + 多标签分类”，声源分离只比较其是否真正提升下游识别。详细判断、训练样本构造与实验闸门见[混合声景意见吸收与技术路线修订](./04-混合声景意见吸收与技术路线修订.md)。

## 3. 音频预处理项目

### 3.1 FFmpeg

- 项目：[FFmpeg](https://ffmpeg.org/)
- 用途：将浏览器上传的 WebM、M4A、MP3 等统一为模型要求的单声道 WAV，完成重采样、裁剪和响度处理。
- 结论：**后端必选基础设施。**

### 3.2 librosa / torchaudio

- 项目：[librosa](https://librosa.org/) / [torchaudio](https://pytorch.org/audio/stable/index.html)
- 用途：加载音频、梅尔频谱、带通滤波、特征分析、数据增强。
- 结论：与最终模型框架一致即可，不需要同时重度使用两套库。

### 3.3 DeepFilterNet

- 项目：[Rikorose/DeepFilterNet](https://github.com/Rikorose/DeepFilterNet)
- 作用：低复杂度全频带噪声抑制，支持命令行和 Python。
- 许可：MIT/Apache-2.0 双许可。
- 结论：**只作为对照实验，不默认放进主链路。**

DeepFilterNet 的主要目标是语音增强。它可能把细小虫鸣或高频动物信号当作噪声抹掉，所以必须比较“原始音频、简单带通、DeepFilterNet”三组识别指标，不能凭人耳觉得更干净就采用。

### 3.4 noisereduce

- 项目：[timsainb/noisereduce](https://github.com/timsainb/noisereduce)
- 作用：基于频谱门控的通用降噪。
- 结论：适合快速建立传统算法基线，参数少、易集成，但同样要以识别准确率而不是听感做决策。

### 3.5 Demucs

- 项目：[facebookresearch/demucs](https://github.com/facebookresearch/demucs)
- 作用：音乐声源分离。
- 结论：**低优先级。** 它主要分离音乐中的人声、鼓、贝斯等，并非为城市自然声设计，不建议作为物种识别前处理的默认选择。

## 4. 网页录音与可视化

### 4.1 浏览器原生能力

- `MediaRecorder`：录制手机麦克风；
- Web Audio API：实时音量、波形和频谱；
- `AudioWorklet`：需要更稳定的实时音频处理时使用。

### 4.2 Meyda

- 项目：[Meyda](https://meyda.github.io/)
- 作用：浏览器端实时/离线音频特征，包括 RMS、频谱质心和滚降频率等。
- 结论：适合制作录音质量提示和声纹动画，但这些特征不能直接替代物种识别模型。

### 4.3 WaveSurfer.js

- 项目：[WaveSurfer.js](https://wavesurfer.xyz/)
- 作用：展示录音波形、播放区间和标记有效片段。
- 结论：可显著缩短前端音频交互开发时间。

## 5. 开放或可申请的自然声音数据源

### 5.1 Xeno-canto

- 网站：[Xeno-canto](https://xeno-canto.org/)
- 内容：以鸟类为主，也包含直翅目昆虫、蝙蝠、蛙类和陆生哺乳动物声音。
- 获取：支持检索和 API；自 2025-10-10 起，下载录音需要 API key，使用前应查看最新 API 说明。
- 许可：每条录音具有独立 Creative Commons 许可，元数据包含许可 URL。
- 推荐程度：**全球数据首选入口。**

使用原则：

- 只下载目标物种和目标地区；
- 第一轮优先质量等级 A/B；
- 保存录音 ID、作者、国家、经纬度、日期、质量和许可 URL；
- 如果未来可能商业化，优先筛选允许商业使用的 CC0、CC BY、CC BY-SA，排除带 NC 的素材；
- 带 SA 的素材涉及衍生内容时需要进一步判断同方式共享义务；
- 不把第三方整理包标注的统一许可证直接当作原始录音许可证。

### 5.2 中国境内 401 种鸟声整理集

- 数据页：[Bird_audio_in_China 数据介绍](https://www.selectdataset.com/dataset/300d2a91ea4d1e1cf41fe0c0278bc114)
- 内容：页面称包含中国境内 401 种鸟、6,507 个文件，约 51.4 GB，源声音来自 Xeno-canto。
- 推荐程度：**适合快速筛选中国候选物种，但许可需重点复核。**

该整理集页面标注 Apache-2.0，但原始声音来自 Xeno-canto，而每条原始录音可能采用不同 CC 许可证。代码/整理文件的许可证不能自动覆盖原始音频版权。使用前必须恢复并保留每条声音的 Xeno-canto 来源与原始许可证；如果无法追溯，不建议作为正式产品训练集或公开素材。

### 5.3 BioONE 鸟类鉴定声音数据集

- 数据页：[BioONE 鸟类鉴定声音数据集](https://bio-one.org.cn/BioResource.html?guid=980a5cd9-9ba7-11e8-bcaa-f8bc123b8e1e)
- 内容：面向物种识别训练和鸟类声音研究的常见鸟类录音。
- 开放情况：页面显示无开放 API；具体下载、申请和使用条款需进一步联系或注册确认。
- 推荐程度：**国内物种数据候选，先确认获取方式和授权。**

### 5.4 海南热带雨林国家公园常见鸟类鸣声数据集

- 数据页：[《生物多样性》数据论文与数据集说明](https://www.biodiversity-science.net/CN/Y2025/V33/I11/25194)
- 内容：46 种常见鸟类，包括 AI 筛选鸣声、人工复核高质量鸣声、记录表、设备信息和物种名录。
- 推荐程度：**高质量国内强候选。**

优势是包含人工复核数据和采样设备信息，适合评估真实声景中的识别能力。局限是地域集中于海南，未必覆盖项目所在地常见物种。下载和再利用时以数据集页面给出的正式许可证和引用要求为准。

### 5.5 中国无尾两栖类鸣声专题库

- 数据页：[国家标本资源平台无尾两栖类鸣声专题库](https://www.nsii.org.cn/2017/AnuraVoice.php/)
- 内容：中国蛙类等无尾两栖动物鸣声及相关物种资料。
- 推荐程度：**两栖类本土数据首要候选。**

需要继续确认是否支持原始音频下载、是否有批量接口、是否仅供在线浏览，以及训练模型和生成展示内容分别需要什么授权。

### 5.6 Macaulay Library

- 网站：[Macaulay Library](https://www.macaulaylibrary.org/)
- 内容：鸟类为主，同时收录两栖、鱼类和哺乳类等自然历史音频、图片和视频。
- 推荐程度：**适合查找参考素材和申请使用，不宜默认批量抓取。**

官方说明资源可面向研究、教育和商业场景申请使用，但具体媒体有贡献者版权和使用要求。例如其鸟声指南明确为个人使用，外部用途需要另行申请。应通过官方 media request 流程，而不是自行批量抓取。

### 5.7 BirdSet

- 数据集：[DBD-research-group/BirdSet](https://huggingface.co/datasets/DBD-research-group/BirdSet)
- 内容：超过 6,800 小时、近 10,000 类的鸟类生物声学训练与评测集合。
- 许可：数据卡标注 CC-BY-NC-4.0。
- 推荐程度：**适合学术评测和预训练研究，不适合未来商业训练主数据。**

BirdSet 规模大、元数据完整，适合研究模型泛化和建立评测基线。但体积大、依赖版本有要求，而且非商业限制与产品化方向冲突，比赛阶段可以使用，商业化前必须替换或获得授权。

### 5.8 BirdCLEF 数据集

- 平台：[Kaggle BirdCLEF](https://www.kaggle.com/competitions?search=BirdCLEF)
- 内容：历年鸟类或多类群声音识别比赛训练数据和真实声景测试数据。
- 推荐程度：**适合研究训练方法和声景评测。**

不同年份覆盖的地区、物种和许可不同，不能统一判断。下载前要逐届阅读 Competition Rules、Data 页面和数据来源；比赛数据许可也不必然允许产品再发布。

### 5.9 InsectSet47 / InsectSet66

- 数据集：[Zenodo 记录](https://zenodo.org/records/8252141)
- 内容：直翅目和蝉科声学识别数据；InsectSet66 含 66 种、1,554 条录音、超过 24 小时。
- 推荐程度：**昆虫识别方法验证候选。**

其物种主要服务既有研究区域，不应假设覆盖中国公园常见蝉和蟋蟀。适合验证“嵌入 + 小分类器”路线，正式目标物种仍需本地数据。

### 5.10 Earth Species Project 数据集合

- 入口：[Hugging Face bioacoustics 数据集列表](https://huggingface.co/datasets?other=bioacoustics)
- 代表项目：BEANS-Zero、BEANS-Next、NatureLM-audio-training、AnimalSpeak 等。
- 推荐程度：**适合模型评测和跨物种研究，需逐子集检查许可。**

这些集合经常聚合多个来源，不同子集可能具有不同授权条件。例如 BEANS-Zero 的部分数据只允许学术、研究或非商业使用，不能只看聚合页标签。

### 5.11 FSD50K / AudioSet

- 数据集：[FSD50K](https://zenodo.org/records/4060432) / [AudioSet](https://research.google.com/audioset/)
- 内容：广义环境声音事件，如鸟、昆虫、风、雨、人声、车辆等。
- 推荐程度：**适合训练录音质量判断和背景声音分类，不适合细粒度物种识别。**

AudioSet 官方发布主要是标签和特征，原音频来自 YouTube，存在视频失效和原始内容版权问题。FSD50K 的单条 Freesound 音频也可能具有不同 CC 许可证，使用时仍需按素材追踪。

## 6. 物种知识、图片与分布数据

声音识别之外还需要可靠的物种名称、图片、分布和科普事实。

### iNaturalist API

- 文档：[iNaturalist API v2](https://api.inaturalist.org/v2/docs/)
- 用途：物种信息、观察记录、地区物种候选和带许可的观察图片。
- 注意：观察记录和媒体具有各自的许可证；写操作需要认证，读取字段可通过 API 精确选择。

### GBIF

- 文档：[GBIF Developer APIs](https://techdocs.gbif.org/en/openapi/)
- 用途：学名校验、分类层级、出现记录和分布辅助。
- 注意：GBIF 适合做分类与分布数据，不是主要声音库；每条 occurrence 和媒体仍保留来源与许可。

### 中国两栖类信息系统

- 网站：[AmphibiaChina](https://www.amphibiachina.org/)
- 用途：中国两栖动物名录、分类和物种资料。
- 注意：适合事实核验和人工建库，不能未经许可复制整站内容。

## 7. 音乐和视频生成开源项目

### AudioCraft / MusicGen

- 项目：[facebookresearch/audiocraft](https://github.com/facebookresearch/audiocraft)
- 作用：文本或旋律条件音乐生成、声音生成和音频编解码。
- 许可：代码 MIT；官方模型权重 CC-BY-NC-4.0。
- 结论：可以做非商业比赛 Demo，但不应在未来商业版中无条件沿用权重。

推荐第一版不直接要求模型“保持物种声音并创作完整音乐”，而是：

```text
原始自然声保留为前景
+ AI 生成无自然声的背景音乐
+ FFmpeg 自动混音、淡入淡出和响度控制
```

比赛指定或推荐的 ThinkSound、Qwen 多模态和 Wan 视频模型可作为托管生成能力，但它们不属于本轮“本地开源可控”路线，后续应单独核实 API、价格、内容许可和稳定性。

## 10. 第一轮验证实验

### 实验 A：确定本地候选物种

由生态成员根据项目所在地、7–8 月季节和公园可达性列出 10–20 种候选，再按以下条件缩到 5–10 种：

- 当季确实活跃；
- 声音特征明显；
- 手机能录到；
- BirdNET 或公开数据覆盖较好；
- 不与其他候选高度混淆；
- 能讲出适合儿童的行为故事。

### 实验 B：BirdNET 零开发基线

每种物种准备至少 20 条来源不同的公开片段和 5–10 条本地手机录音，同时准备人声、交通、风雨和其他物种负样本。记录 Top-1、Top-3、误报率和推理耗时。

### 实验 C：预处理消融

对同一测试集比较：

1. 原始音频；
2. 响度归一化；
3. 简单带通滤波；
4. noisereduce；
5. DeepFilterNet。

只根据识别指标选择方案，不按人耳听感选择。

### 实验 D：自定义分类器

当 BirdNET 默认类别覆盖不足时，分别测试：

- BirdNET embedding + 自定义分类头；
- Perch 2.0 embedding + Logistic Regression/小型 MLP；
- OpenSoundscape 训练轻量 CNN。

所有路线都必须加入 `unknown/background` 数据，并单独测量未知类拒识效果。

## 11. 技术选型建议

### 比赛 MVP 推荐组合

| 环节 | 推荐方案 | 备选 |
|---|---|---|
| 手机录音 | MediaRecorder + Web Audio API | 原生 App 后置 |
| 波形/频谱 | WaveSurfer.js + Meyda | Canvas 自绘 |
| 后端 | Python + FastAPI | Flask |
| 转码 | FFmpeg | 无 |
| 杭州 6 种鸟基线 | BirdNET | Perch 小分类器 |
| 7 类混合声景识别 | BirdNET embedding + 多标签 MLP | Perch 2.0 / OpenSoundscape |
| 黑蚱蝉补充 | 自定义多标签分类头 | Perch 2.0 / AVES |
| 预处理 | 原音 + 轻度带通双路 | noisereduce |
| 科普知识 | 人工结构化 JSON/数据库 | iNaturalist/GBIF 辅助 |
| 儿童表达 | 比赛推荐大模型 | 本地 LLM 后置 |
| 音乐 | 原声 + 生成背景乐混音 | MusicGen melody |
| 视频 | 模板合成优先 | 视频生成模型作为增强 |

### 暂不推荐进入主链路

- 用通用语音降噪直接覆盖原始自然声；
- 把 TF-GridNet 当作无需生物声学训练数据即可使用的成品；
- 为了分离而丢弃原始音频识别结果；
- 从零训练大型声音基础模型；
- 一开始覆盖上百种物种；
- 依赖 Macaulay Library 未授权批量抓取；
- 将 AudioSet 当作细粒度物种数据集；
- 用声学指数直接宣称生境健康度；
- 没有 unknown 类却展示非常精确的置信度。
