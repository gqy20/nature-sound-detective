# 非鸟分类头 v0.3 评估记录

## 范围

- 模型版本：`hangzhou-nonbird 0.3.0`
- 类别数：10（7 个具体物种/实验物种、2 个泛类、1 个背景拒识类）
- 训练输入：复用 BirdNET 2.4 的 1024 维 embedding
- 数据：283 个独立来源录音，1,899 个 3 秒窗口
- 测试：316 个窗口；压力测试：2,318 个窗口

新增实验类为中国雨蛙、黑斑侧褶蛙、北方狭口蛙、蟪蛄和蒙古寒蝉。实验类阈值不得低于物种配置中的 `default_threshold`，避免小验证集将阈值校准得过低。

## 压力测试

压力条件包含 `snr_-5/0/5/10/15`、静音衰减、混响、手机频带和干净背景。30 个干净背景窗口的非背景误报率为 0；所有实验类继续使用高精度优先的阈值下限。

## 发布边界

- 可以作为端侧“声音线索”展示：中国雨蛙、蟪蛄。
- 低召回实验候选：北方狭口蛙、蒙古寒蝉。
- 数据不足、暂不承诺识别率：黑斑侧褶蛙。
- 所有来源标签结果仍需杭州公园真实录音复验。
